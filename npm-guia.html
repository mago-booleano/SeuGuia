O que é npm?

npm é o gerenciador de pacotes do Node.js. Ele instala bibliotecas, registra scripts e resolve dependências.

npm --version
node --version
npm help

1. Instalação

node -v
Mostra a versão instalada do Node.js. 
node --version
npm -v
Mostra a versão do npm. 
npm --version
Atualizar o npm
Atualiza o npm globalmente. No Windows, execute o terminal como administrador quando necessário. 
npm install --global npm@latest
PowerShell
Se scripts estiverem bloqueados, apenas habilite scripts locais quando você confia no ambiente. 
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
npm run dev

2. Versões e modos de instalação

Versões exatas

"react": "19.1.0"

Instala exatamente a versão informada.

Patch automático

"react": "~19.1.0"

Adequado para alterações de patch da mesma linha.

Minor e patch

"react": "^19.1.0"

Permite atualizações compatíveis dentro da versão principal.

Qualquer versão

"react": "*"

Permite a versão mais nova compatível encontrada pelo npm.

3. Criar e configurar projetos

npm init
Cria o package.json por perguntas interativas. 
npm init
npm init -y
Cria o arquivo usando respostas padrão. 
npm init -y
npm install
Instala todas as dependências registradas no projeto. 
npm install
package.json
Arquivo principal do projeto. 
{
  "name": "meu-projeto",
  "version": "1.0.0",
  "scripts": {
    "dev": "vite",
    "build": "vite build"
  },
  "dependencies": {},
  "devDependencies": {}
}

4. Pacotes e dependências

npm install pacote
Instala em dependencies, usado pela aplicação em produção. 
npm install express
npm install -D pacote
Instala em devDependencies, usado apenas no desenvolvimento. 
npm install --save-dev vite
npm uninstall pacote
Remove o pacote e atualiza os arquivos de dependência. 
npm uninstall express
npm list
Lista pacotes instalados e suas dependências. 
npm list
npm list --depth=0
npm view
Consulta informações de um pacote sem instalá-lo. 
npm view vite version
npm view react description
package-lock.json fixa o grafo exato de dependências. Não apague ou edite manualmente. node_modules pode ser reconstruído por npm install.

5. npx

npx é um atalho moderno para npm exec. Ele procura o comando em node_modules/.bin, nos scripts locais e no cache; se não estiver instalado, pode baixar e executar o pacote temporariamente.

Instalar ferramentas globalmente não é obrigatório. Para projetos, prefira deixar ferramentas importantes em devDependencies e executá-las por npm exec ou npx.
Sintaxe básica
Executa o binário publicado pelo pacote. 
npx nome-do-pacote
npx nome-do-pacote argumento1 argumento2
npm exec -- nome-do-pacote argumento
npx --yes pacote
Confirma automaticamente a instalação do pacote. No npm moderno, é útil em scripts e instalações não interativas. 
npx --yes create-vite@latest meu-app
npx -y prettier --write index.html
npx --package
Define um pacote diferente do nome do executável que será executado. Use -- para separar opções do npm dos argumentos do programa. 
npx --package typescript tsc --init
npx --package=cowsay cowsay "Olá npm"
npx --package typescript --package ts-node ts-node arquivo.ts
npx pacote@versao
Executa uma versão específica ou a versão mais recente do pacote. 
npx prettier@3 --write index.html
npx vite@latest
npx create-react-app@latest meu-app
npx create-next-app@latest meu-app
        npx --package typescript@5 tsc --version
npx -p
Forma abreviada de --package. A sintaxe completa pode ser mais clara em arquivos automatizados. 
npx -p typescript tsc --version
npx -p eslint eslint src
npx --call
Executa um comando composto ou uma sequência dentro do ambiente temporário criado pelo npm. 
npx --package typescript --call "tsc --noEmit"
npx --package rimraf --call "rimraf dist"
npx --workspace
Executa um binário em um workspace específico de um monorepo. 
npx --workspace=web vite --host
npx --workspace=api prisma generate
npx --prefix
Altera o diretório usado pelo npm para localizar o projeto e suas dependências. 
npx --prefix ./frontend vite --host
npx --prefix ./frontend prettier --write src

Criadores de projetos

Vite
Cria projetos de frontend com ou sem framework. 
npx create-vite@latest
npx create-vite@latest meu-app --template react
npx create-vite@latest meu-app --template vue
npx create-vite@latest meu-app --template vanilla
React
Cria uma aplicação baseada no create-react-app legado ou utiliza outras ferramentas modernas de React. 
npx create-react-app meu-app
npx create-react-app meu-app --template typescript
Next.js
Inicializa uma aplicação Next.js interativa ou com opções fixadas. 
npx create-next-app@latest meu-app
npx create-next-app@latest meu-app --typescript
npx create-next-app@latest meu-app --eslint --app
TypeScript e Node.js
Inicializa configurações para executores e servidores TypeScript. 
npx tsc --init
npx tsx server.ts
npx ts-node server.ts
npx ts-node-dev --respawn server.ts
npx nodemon server.js
Servidor Express
Gera uma estrutura inicial de Express. --view escolhe uma engine de templates. 
npx express-generator meu-servidor
npx express-generator meu-servidor --view=ejs
npx express-generator meu-servidor --no-view
Outros scaffolds
Baixa ou gera projetos sem adicionar scaffolding ao package.json atual. 
npx degit usuario/repositorio meu-projeto
npx create-remix@latest
npx nuxi@latest init meu-app
npx @angular/cli@latest new meu-app

Formatar, validar e testar

Prettier
Formata arquivos ou verifica se estão formatados sem modificar o projeto. 
npx prettier --write .
npx prettier --write index.html src
npx prettier --check .
npx prettier --list-different "src/**/*.{js,ts}"
ESLint
Cria configuração ou analisa o código-fonte. 
npx eslint --init
npx eslint .
npx eslint src --fix
npx eslint src --max-warnings=0
Testes
Executa Jest, Vitest ou Browserslist sem salvar o runner como dependência permanente. 
npx jest
npx jest --watch
npx jest --coverage
npx vitest
npx vitest --run
npx vitest --coverage
npx browserslist
TypeScript
Compila ou verifica tipos sem gerar arquivos JavaScript. 
npx tsc
npx tsc --noEmit
npx tsc --watch
npx tsc --project tsconfig.json
npx tsc --showConfig

Servidores locais e rede

Vite
Inicia o servidor de desenvolvimento, configurando host e porta. 
npx vite
npx vite --host
npx vite --host 0.0.0.0
npx vite --port 3000
npx vite --open
npx vite --host --port 4173
Servidores estáticos
Publica temporariamente uma pasta pelo navegador local. 
npx serve .
npx serve -l 5000 .
npx http-server .
npx http-server -p 8080 -c-1
npx live-server
Aplicações completas
Execute o servidor de desenvolvimento definido pela ferramenta. Nestes exemplos, --package baixa a CLI e executa seu programa de linha de comando. 
npx --package @angular/cli ng serve
        npx --package @vue/cli vue-cli-service serve
npx next dev
npx nuxt dev

Automação, segurança e análise

Atualizações e auditoria
Consulta e atualiza versões de pacotes sem editar manualmente todo o package.json. 
npx npm-check-updates
npx npm-check-updates -u
npm audit
npx license-checker
npx license-checker --summary
Segurança e dependências
Analisa vulnerabilidades, dependências ou arquivos conhecidos como inseguros. 
npx snyk test
npx audit-ci
npx depcheck
npx madge --circular src
npx madge --image graph.svg src
Desempenho e acessibilidade
Executa verificadores de desempenho ou compatibilidade no navegador. 
npx lighthouse https://exemplo.com
npx lighthouse http://localhost:3000 --view
npx pa11y http://localhost:3000
npx unlighthouse --site http://localhost:3000
Playwright e navegadores
Instala navegadores e inicia scripts de automação. 
npx playwright install
npx playwright install chromium
npx playwright install --with-deps
npx playwright test
npx playwright test --ui
npx playwright codegen http://localhost:3000

Comandos úteis de sistema

Remover diretórios
Remove uma pasta de forma compatível com vários sistemas ou shells. 
npx rimraf dist
npx rimraf dist coverage
npx rimraf node_modules/.cache
Variáveis de ambiente
Define temporariamente variáveis conforme o sistema operacional. 
npx cross-env NODE_ENV=production node server.js
npx cross-env PORT=3000 npm run start
npx env-cmd -f .env node server.js
Arquivos e comandos do sistema
Executa ferramentas pequenas sem instalá-las permanentemente. 
npx open-cli https://example.com
npx nanoid
npx cowsay "Meu projeto funciona"
npx sort-package-json
npm pkg get scripts
npm pkg set name="novo-nome"

Comandos e flags importantes

npx --help
Mostra ajuda geral do npm exec e npx. 
npx --help
npm exec --help
npx pacote --help
npx --no-install
Em versões antigas do npm, impedia a instalação automática. Use versões novas como preferência pela verificação local e npx --yes; consulte npx --help para confirmar o suporte da sua versão. 
npx --no-install prettier --check .
npx -c
Executa um comando completo dentro do shell de pacote em versões/fluxos compatíveis. 
npx -p cowsay -c "cowsay 'Executado pelo npx'"
Procure não executar pacotes desconhecidos com npx. Verifique o nome exato no npm, use uma versão fixa quando possível e revise scripts de build antes de executá-los.

7. Mais comandos npm explicados

npm ci
Instala exatamente as dependências do package-lock.json. É mais indicado para automações e integrações contínuas. Apaga o node_modules atual antes de instalar. 
npm ci

Use quando o lockfile está atualizado e você quer reproduzir a instalação. Para desenvolvimento comum, npm install costuma ser mais conveniente.

npm exec
Executa uma ferramenta de pacote. É a forma atual do que normalmente se faz com npx. 
npm exec -- prettier --check .
npm exec -- vite --host

O -- separa as opções do npm dos argumentos do programa executado.

npm pkg
Lê ou altera campos do package.json sem abrir o arquivo manualmente. 
npm pkg get scripts
npm pkg get name
npm pkg set scripts.lint="eslint ."
npm pkg delete scripts.old

Confira a alteração depois com npm pkg get ou lendo o arquivo.

npm explain
Explica por que um pacote está instalado, mostrando qual dependência o trouxe. 
npm explain vite
npm explain lodash
npm ls
É o mesmo comando que npm list. Mostra dependências locais; --depth=0 limita a lista aos pacotes principais. 
npm ls
npm ls --depth=0
npm ls typescript
npm dedupe
Tenta reduzir cópias repetidas de uma mesma dependência na árvore instalada. 
npm dedupe
npm dedupe --dry-run

Ele reorganiza instalações compatíveis; não é necessário rodar de rotina em todo projeto.

npm prune
Remove pacotes instalados que não estão declarados no package.json. 
npm prune
npm prune --omit=dev
npm root
Mostra o caminho da pasta onde o npm instala dependências. 
npm root
npm root --global
npm config
Consulta e ajusta preferências do npm, como o registro usado para baixar pacotes. 
npm config get registry
npm config list
npm config set fund false

Configurações podem ser locais ao projeto ou globais. Evite gravar senhas ou tokens em arquivos compartilhados.

npm cache
Verifica o cache de downloads. Em geral, o npm gerencia esse cache sozinho. 
npm cache verify

Não limpe o cache como primeira tentativa para qualquer erro; comece lendo a mensagem do npm.

npm version
Mostra ou atualiza a versão do projeto no package.json. As formas patch, minor e major aumentam partes diferentes da versão. 
npm version
npm version patch
npm version minor
npm version major

Isso pode criar um commit e uma tag, dependendo da configuração do repositório.

npm publish
Publica o pacote no registro npm. Antes, confira o nome, a versão, os arquivos incluídos e se não há segredos. 
npm pack --dry-run
npm publish --access public

npm pack --dry-run ajuda a revisar o conteúdo sem publicar nada.

npm pack
Cria um arquivo compactado com os arquivos que seriam distribuídos pelo pacote. 
npm pack --dry-run
npm pack
npm uninstall global
Remove um pacote que foi instalado globalmente. Em geral, prefira dependências locais por projeto. 
npm uninstall --global nome-do-pacote
npm help
Abre a ajuda geral ou a documentação de um comando. 
npm help
npm help install
npm help scripts

8. Auditoria e manutenção

npm outdated
Lista dependências que possuem versões novas. 
npm outdated
npm update
Atualiza dentro das regras do package.json e package-lock.json. 
npm update
npm audit
Verifica vulnerabilidades conhecidas. 
npm audit
npm audit fix
npm audit fix --force
Use --force apenas depois de revisar alterações incompatíveis.
npm cache
Consulta ou limpa o cache local. 
npm cache verify
npm cache clean --force
