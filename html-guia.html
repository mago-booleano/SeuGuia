1. Estrutura do documento

<html>
Elemento raiz. lang define o idioma do documento. 
<html lang="pt-BR">
<head>
Contém metadados e recursos não exibidos diretamente na página. 
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Minha página</title>
  <link rel="stylesheet" href="style.css">
</head>
<meta>
Define charset, viewport, descrição, tema e outros metadados. É uma tag sem fechamento. 
<meta name="description" content="Descrição da página">
<meta name="theme-color" content="#071009">
<body>
Contém todo o conteúdo visual do documento.

2. Texto e conteúdo semântico

Títulos

<h1>Título principal</h1>
<h2>Subtítulo</h2>
<h3>Seção menor</h3>

Use apenas um h1 principal e mantenha hierarquia.

Texto

<p>Parágrafo.</p>
<strong>Importante</strong>
<em>Ênfase</em>
<small>Observação</small>
<br>

Listas

<ul><li>Não ordenado</li></ul>
<ol><li>Ordenado</li></ol>
<dl><dt>Termo</dt><dd>Descrição</dd></dl>

Citações e código

<blockquote>Citação</blockquote>
<q>Citação curta</q>
<code>const x = 1;</code>
<pre>Texto preservado</pre>
<header>
Introdução ou cabeçalho de uma seção.
<nav>
Contém links de navegação principal ou secundária.
<main>
Conteúdo principal e único da página.
<section>
Agrupa conteúdo temático com título apropriado.
<article>
Representa conteúdo independente, como notícia ou postagem.
<aside>
Conteúdo relacionado, complementar ou lateral.
<footer>
Rodapé de página ou seção.
<div> e <span>
div agrupa elementos em bloco. span agrupa conteúdo em linha. Use semântica específica sempre que existir. 
<div class="cartao">...</div>
<span class="destaque">Texto</span>

3. Links e mídia

<a>
Cria links. href pode apontar para página, âncora, email ou telefone. 
<a href="pagina.html">Página</a>
<a href="#contato">Contato</a>
<a href="mailto:teste@email.com">Email</a>
<a href="pagina.html" target="_blank" rel="noopener">Nova aba</a>
<img>
Insere uma imagem. alt descreve o conteúdo para acessibilidade e falhas de carregamento. 
<img src="foto.jpg" alt="Descrição da foto" width="800" height="400">
<picture>
Permite escolher uma imagem conforme tamanho ou formato. 
<picture>
  <source srcset="foto-grande.webp" media="(min-width: 800px)" type="image/webp">
  <img src="foto-pequena.jpg" alt="Descrição">
</picture>
<video>
controls, autoplay, muted, loop, poster e preload controlam reprodução. 
<video controls width="640" poster="capa.jpg">
  <source src="video.mp4" type="video/mp4">
</video>
<audio>
Reproduz áudio com controles ou automaticamente quando permitido pelo navegador. 
<audio src="audio.mp3" controls></audio>
<iframe>
Exibe outra página incorporada. Use title e permissões apropriadas. 
<iframe src="pagina.html" title="Página incorporada"></iframe>

4. Tabelas

<table>
Representa dados tabulares. Use caption, thead, tbody, th e td. 
<table>
  <caption>Alunos</caption>
  <thead><tr><th scope="col">Nome</th></tr></thead>
  <tbody><tr><td>Ana</td></tr></tbody>
</table>
colspan / rowspan
Mesclam células horizontal ou verticalmente. 
<td colspan="2">Duas colunas</td>
<td rowspan="2">Duas linhas</td>

5. Formulários e campos

<form>
action define o destino e method define GET ou POST. 
<form action="/buscar" method="get">...</form>
<label>
Associa texto ao campo usando o atributo for com o mesmo id do campo. 
<label for="email">Email</label>
<input id="email" name="email" type="email" required>
<input>
Tipos comuns: text, email, password, number, tel, search, date, time, color, checkbox, radio, file, range e submit. 
<input type="checkbox" name="ativo" checked>
<input type="radio" name="plano" value="pro">
<input type="number" min="1" max="10" step="1">
<textarea>
Campo multilinha com rows, cols, placeholder e maxlength. 
<textarea name="mensagem" rows="5" required></textarea>
<select>
Lista de opções. multiple permite várias escolhas. 
<select name="cidade">
  <option value="">Selecione</option>
  <option value="sp">São Paulo</option>
</select>
<button>
type pode ser submit, reset ou button. 
<button type="submit">Enviar</button>
Validação HTML
required, minlength, maxlength, min, max, step, pattern e placeholder ajudam na validação e orientação. 
<input pattern="[0-9]{3}" title="Informe três números">

6. Atributos globais

Identificação

id="principal"
class="cartao ativo"
title="Texto de ajuda"
lang="pt-BR"

Conteúdo e dados

contenteditable="true"
hidden
tabindex="0"
data-id="123"

Direção e idioma

dir="ltr"
dir="rtl"
spellcheck="true"
translate="no"

Eventos e atributos gerais

style="color: red"
draggable="true"
part="conteudo"
exportparts="titulo: card-title"
id
Identificador único no documento. Usado por âncoras, labels, CSS e JavaScript.
class
Lista de classes separadas por espaço. Permite aplicar estilos ou grupos JavaScript.
title
Informação auxiliar exibida normalmente em uma tooltip.
hidden
Remove o elemento da apresentação até que o atributo seja removido ou o CSS/JavaScript o altere.
data-*
Armazena dados personalizados acessíveis pelo DOM e JavaScript. 
<button data-acao="copiar" data-id="42">Copiar</button>
tabindex
Controla a ordem ou inclui elementos na navegação por teclado. Preferencialmente use elementos nativos quando possível.

7. Acessibilidade

aria-label
Fornece um nome acessível quando não existe texto visível. 
<button aria-label="Fechar menu">×</button>
aria-labelledby
Usa o texto de outro elemento como nome acessível. 
<section aria-labelledby="titulo">
  <h2 id="titulo">Configurações</h2>
</section>
aria-describedby
Associa uma descrição explicativa a um elemento.
aria-expanded
Indica se um conteúdo associado está aberto ou fechado. 
<button aria-expanded="false" aria-controls="menu">Abrir</button>
aria-current
Indica o item atual em uma coleção ou navegação. 
<a href="/" aria-current="page">Página atual</a>
Prefira elementos semânticos e nativos. Só use ARIA quando o HTML padrão não representa o comportamento.
