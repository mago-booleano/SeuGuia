Instalação do npm

Para permitir a execução de scripts no PowerShell do VS Code:

Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned

Verificando versões

Mostra a versão do Node.js instalada:

node -v

Mostra a versão do npm instalada:

npm -v

Mostra a versão completa do executável do npm:

npm --version

Exibe informações detalhadas sobre o ambiente Node.js e npm:

npm config list

Abre o painel de configuração do npm no navegador:

npm config list --json

Gerenciamento de pacotes

  • Instala dependências do projeto:
    npm install
  • Instala um pacote:
    npm install pacote
  • Instala um pacote como dependência de desenvolvimento:
    npm install -D pacote
  • Remove um pacote:
    npm uninstall pacote
  • Lista os pacotes instalados:
    npm list
  • Mostra os scripts disponíveis do projeto:
    npm run
  • Executa um pacote temporário sem instalação global:
    npx
  • Instala um pacote como dependência normal:
    npm install express --save
  • Instala um pacote como dependência global:
    npm install -g typescript
  • Instala uma versão específica de um pacote:
    npm install react@18.3.1
  • Instala a versão mais recente dentro da faixa aceita:
    npm install react@latest
  • Remove um pacote de todas as dependências:
    npm uninstall express
  • Pesquisa pacotes disponíveis no registro npm:
    npm search express
  • Exibe informações sobre um pacote:
    npm view react description
  • Instala todas as dependências do package.json:
    npm install --package-lock-only
  • Limpa pacotes não referenciados por dependências:
    npm prune
  • Reinstala dependências ausentes ou corrompidas:
    npm rebuild
  • Executa uma versão temporária de uma ferramenta:
    npx prettier --write .
  • Mostra os pacotes desatualizados em formato detalhado:
    npm outdated --long

Scripts do projeto

  • Executa o script de inicialização, se definido no package.json:
    npm start
  • Executa o script de desenvolvimento, se definido no package.json:
    npm run dev
  • Executa os testes definidos no projeto:
    npm test
  • Gera a versão de produção, se houver esse script:
    npm run build
  • Executa o script com argumentos adicionais:
    npm run dev -- --host 0.0.0.0
  • Executa um script de forma silenciosa:
    npm run build --silent
  • Executa todos os scripts cujo nome começa com "test":
    npm run test:unit
  • Mostra o diretório usado por pacotes executáveis locais:
    npx which vite

Instalação e atualização

  • Instala exatamente as versões do package-lock.json:
    npm ci
    Requer um arquivo package-lock.json ou npm-shrinkwrap.json.
  • Atualiza dependências dentro das versões permitidas no package.json:
    npm update
  • Mostra dependências com versões mais recentes disponíveis:
    npm outdated
  • Lista apenas as dependências diretas do projeto:
    npm list --depth=0
  • Atualiza apenas um pacote específico:
    npm update react
  • Atualiza todas as dependências de desenvolvimento:
    npm update --save-dev
  • Corrige vulnerabilidades incluindo mudanças compatíveis:
    npm audit fix --force
    Use com cuidado: pode gerar mudanças incompatíveis.
  • Gera um relatório JSON da auditoria:
    npm audit --json
  • Limpa o cache global do npm:
    npm cache clean --force
  • Mostra o tamanho do diretório de cache:
    npm cache size
  • Lista os usuários publicados no npm:
    npm whoami
  • Publica o pacote atual no registro configurado:
    npm publish
  • Remove uma versão publicada do pacote:
    npm unpublish nome-do-pacote@1.0.0
  • Executa o npm em modo diagnóstico:
    npm doctor

Auditoria e manutenção

  • Verifica vulnerabilidades conhecidas nas dependências:
    npm audit
  • Tenta corrigir vulnerabilidades sem mudanças incompatíveis:
    npm audit fix
    Pode atualizar o package-lock.json. Revise as alterações antes de enviar o projeto.
  • Verifica a integridade do cache local do npm:
    npm cache verify

Comandos Git

Execute os comandos no terminal, dentro da pasta do projeto. Troque os valores de exemplo pelos seus dados.

  • Confere se o Git está instalado:
    git --version
  • Configura seu nome para os commits:
    git config --global user.name "Seu Nome"
  • Configura seu e-mail para os commits:
    git config --global user.email "voce@exemplo.com"
  • Inicia um repositório Git na pasta atual:
    git init
  • Baixa uma cópia de um repositório remoto:
    git clone URL_DO_REPOSITORIO
    Substitua pelo endereço HTTPS ou SSH do repositório.
  • Mostra arquivos modificados e o estado do repositório:
    git status
  • Prepara um arquivo para o próximo commit:
    git add nome-do-arquivo
  • Prepara todas as alterações da pasta:
    git add .
  • Registra as alterações preparadas:
    git commit -m "Descreva a alteracao"
  • Exibe o histórico resumido de commits:
    git log --oneline
  • Mostra alterações ainda não preparadas para commit:
    git diff
  • Mostra alterações já preparadas para commit:
    git diff --staged
  • Lista as branches locais:
    git branch
  • Cria uma branch e muda para ela:
    git switch -c nome-da-branch
  • Muda para uma branch existente:
    git switch nome-da-branch
  • Lista os repositórios remotos configurados:
    git remote -v
  • Conecta o projeto a um repositório remoto:
    git remote add origin URL_DO_REPOSITORIO
    Use quando o projeto ainda não tem um remoto chamado origin.
  • Envia a branch atual e configura o upstream:
    git push -u origin main
    Troque main pelo nome da sua branch, se necessário.
  • Envia novos commits para o remoto:
    git push
  • Baixa e integra alterações da branch remota:
    git pull origin main
    Confirme o nome da branch antes de executar.
  • Baixa informações do remoto sem integrar alterações:
    git fetch
  • Guarda temporariamente alterações ainda não commitadas:
    git stash
  • Restaura as alterações guardadas mais recentemente:
    git stash pop
  • Descarta alterações locais de um arquivo:
    git restore nome-do-arquivo
    Atenção: remove as alterações locais não commitadas desse arquivo.
  • Remove o rastreamento de um arquivo sem apagá-lo do disco:
    git rm --cached nome-do-arquivo
  • Move ou renomeia um arquivo mantendo o histórico:
    git mv antigo.txt novo.txt
  • Mostra o histórico completo com ramificações:
    git log --oneline --graph --decorate --all
  • Mostra os autores e linhas alteradas em um arquivo:
    git blame nome-do-arquivo
  • Localiza o commit que introduziu uma mudança:
    git bisect start
  • Marca o commit atual como bom durante a busca:
    git bisect good
  • Marca o commit atual como ruim durante a busca:
    git bisect bad
  • Finaliza a busca por regressão:
    git bisect reset
  • Exclui uma branch local já integrada:
    git branch -d nome-da-branch
  • Exclui uma branch local mesmo não integrada:
    git branch -D nome-da-branch
  • Exclui uma branch no repositório remoto:
    git push origin --delete nome-da-branch
  • Baixa uma branch remota para uma branch local:
    git switch --track origin/nome-da-branch
  • Mescla uma branch na branch atual:
    git merge nome-da-branch
  • Envia uma branch específica para o remoto:
    git push origin nome-da-branch
  • Busca alterações e atualiza branches remotas:
    git fetch --prune
  • Reaplica commits sobre a branch atual:
    git rebase main
  • Continua um rebase após resolver conflitos:
    git rebase --continue
  • Cancela um rebase em andamento:
    git rebase --abort
  • Copia um commit específico para a branch atual:
    git cherry-pick HASH_DO_COMMIT
  • Cria uma cópia temporária das alterações locais:
    git stash push -m "descricao das alterações"
  • Lista todas as cópias temporárias:
    git stash list
  • Aplica uma stash sem removê-la da lista:
    git stash apply stash@{0}
  • Apaga uma stash específica:
    git stash drop stash@{0}
  • Desfaz um commit criando outro commit reverso:
    git revert HASH_DO_COMMIT
  • Cria uma tag anotada para uma versão:
    git tag -a v1.0.0 -m "Versão 1.0.0"
  • Lista todas as tags do projeto:
    git tag --list
  • Envia todas as tags para o repositório remoto:
    git push origin --tags
  • Desfaz o staging de todos os arquivos:
    git reset
  • Mostra commits ainda não enviados ao remoto:
    git log origin/main..HEAD
  • Abre uma interface gráfica de resolução de conflitos:
    git mergetool

Propriedades CSS

Propriedades são declaradas dentro de seletores no formato propriedade: valor;. Esta referência reúne os principais recursos modernos de texto, posicionamento, dimensões, flexbox, grid, responsividade, cores, animação e acessibilidade.

Como cada valor funciona

  • Palavra-chave: auto, none, block, center e outras opções predefinidas.
  • Comprimento: px, em, rem, %, vw, vh, dvw, dvh, ch ou fr.
  • Número ou proporção: 0, 1, 1.5, 16 / 9, deg, rad, turn, ms ou s.
  • Cor: nome, hexadecimal, rgb(), rgba(), hsl(), hsla(), oklch(), color-mix() ou transparent.
  • Imagem ou função: url(), linear-gradient(), radial-gradient(), conic-gradient(), var(), calc(), min(), max() ou clamp().
  • Valor global: toda propriedade aceita initial (valor inicial), inherit (valor herdado), unset (herdado ou inicial), revert (estilo do agente) e revert-layer (camada anterior).

background-clip Limita o desenho do fundo. border-box: até a borda; padding-box: até o padding; content-box: apenas o conteúdo; text: recorta no texto.
background-origin Define a área de referência do fundo. border-box, padding-box ou content-box.
border Forma abreviada de espessura, estilo e cor. thin/medium/thick/ ; none/hidden/solid/dotted/dashed/double/groove/ridge/inset/outset; cor.

font-weight Define a espessura. normal (400), bold (700), bolder, lighter ou número inteiro entre 1 e 1000.
font-style Escolhe a inclinação da fonte. normal, italic ou oblique; oblique 10deg pode definir o ângulo.

line-height Define a altura das linhas. normal; número sem unidade como 1.5; comprimento como 24px; porcentagem como 150%.
text-align Alinha o conteúdo textual. start, end, left, right, center, justify, match-parent, justify-all.
text-decoration Forma abreviada da decoração. Linha: none/underline/overline/line-through/blink; estilo: solid/double/dotted/dashed/wavy; cor e espessura.
text-transform Transforma a caixa das letras. none, capitalize, uppercase, lowercase, full-width, full-size-kana.
text-wrap Controla a quebra de texto. wrap: quebra normal; nowrap: sem quebra automática; balance: distribui linhas; pretty: evita órfãs; stable: preserva linhas em edição.

word-break Controla onde palavras podem ser quebradas. normal, break-all, keep-all, break-word, auto-phrase.
overflow-wrap Permite quebrar palavras longas. normal, break-word, anywhere.
box-sizing Define o cálculo da largura e altura. content-box: exclui borda/padding; border-box: inclui padding e borda; inherit, initial e unset.
width / height Define dimensões da caixa. auto, comprimento, porcentagem, fit-content, max-content, min-content, stretch, 100vh, 100dvh.
min-* / max-* Limita dimensões mínimas ou máximas. none (sem limite), 0, comprimento, porcentagem, fit-content, min-content, max-content, stretch.
margin Define espaço externo da caixa. auto, comprimento ou porcentagem. Um valor: todos; dois: vertical/horizontal; três: superior/horizontal/inferior; quatro: sentido horário.
padding Define espaço interno da caixa. Comprimento ou porcentagem. Segue a mesma regra de um, dois, três ou quatro valores do margin; não aceita negativos nem auto.
display Define o tipo de caixa e layout externo. none, block, inline, inline-block, flex, inline-flex, grid, inline-grid, flow-root, list-item, table, contents.
position Escolhe o método de posicionamento. static: fluxo normal; relative: desloca a partir de si; absolute: relativo ao ancestral; fixed: relativo à viewport; sticky: fixa ao rolar.
inset Forma abreviada de top/right/bottom/left. auto, comprimento ou porcentagem. Um valor aplica todos; dois vertical/horizontal; três superior/horizontal/inferior; quatro sentido horário.
z-index Controla empilhamento. auto: ordem normal; número inteiro positivo ou negativo altera o nível, por exemplo -1, 0, 10.
overflow Controla conteúdo excedente. visible, hidden, clip, scroll, auto. Pode receber um valor para ambos os eixos ou dois: eixo X/eixo Y.
visibility Mostra ou oculta sem remover o fluxo. visible: mostra; hidden: oculta mas reserva espaço; collapse: oculta linha/coluna de tabela.
opacity Define transparência completa do elemento. 0: totalmente transparente; 0.5: meio transparente; 1: totalmente opaco; também aceita porcentagem como 50%.
flex-direction Define a direção do eixo principal flex. row, row-reverse, column, column-reverse.
flex-wrap Permite quebra dos itens flex. nowrap, wrap, wrap-reverse.
flex Forma abreviada de crescimento, redução e base. none; número como 1 usa fator de crescimento; 1 1 240px usa crescimento, redução e base; auto usa o tamanho natural.

align-items Alinha itens no eixo transversal. normal, stretch, start, end, center, baseline, first baseline, last baseline.
align-self Sobrescreve o alinhamento de um item. auto usa o pai; stretch, start, end, center, baseline, first baseline, last baseline.
gap Define espaço entre linhas e colunas. normal, comprimento ou porcentagem. Um valor: ambos; dois: linha/coluna.
grid-template-columns Define as colunas do grid. none, comprimento, porcentagem, fr, minmax(), repeat(), subgrid, min-content, max-content, auto.
grid-template-rows Define as linhas do grid. none, auto, comprimento, porcentagem, fr, minmax(), repeat(), subgrid.
grid-template-areas Nomeia regiões da grade. none; strings como "header header", "main aside". Pontos representam células vazias.
grid-column / grid-row Posiciona um item na grade. auto, número de linha, nome da linha, span <n>, intervalo como 1 / -1.
place-items Alinha itens nos dois eixos. Combina align-items e justify-items. Um valor: ambos; dois: alinhamento X/alinhamento Y.
place-content Alinha o conteúdo da grade ou flex nos dois eixos. Combina align-content e justify-content, por exemplo center, space-between, stretch.
object-fit Ajusta mídia substituível ao contêiner. fill, contain, cover, none, scale-down.
object-position Posiciona o ponto focal da mídia. left, right, top, bottom, center, porcentagens ou comprimentos como 20% 30%.
transform Aplica transformações geométricas. none; translate(), translateX/Y/Z(), rotate(), scale(), skew(), matrix(), perspective(); funções podem ser combinadas.
transform-origin Define o ponto fixo da transformação. left, center, right, top, bottom, comprimento ou porcentagem.
transition Anima mudanças entre estados. Propriedade, duração, função de tempo e atraso. Funções: linear, ease, ease-in, ease-out, ease-in-out, step-start, step-end, cubic-bezier(), steps().

animation-iteration-count Define quantas vezes ocorre. Número positivo como 3 ou infinite para repetição sem fim.
animation-fill-mode Define estilos fora da execução. none, forwards, backwards, both.
animation-play-state Inicia ou pausa a animação. running ou paused.
filter Aplica efeitos gráficos. none; blur(), brightness(), contrast(), grayscale(), hue-rotate(), invert(), opacity(), saturate(), sepia(), drop-shadow().
backdrop-filter Filtra o conteúdo atrás do elemento. none ou as mesmas funções gráficas de filter: blur(), brightness(), contrast(), saturate() etc.
mix-blend-mode Mistura o elemento com o fundo. normal, multiply, screen, overlay, darken, lighten, color-dodge, color-burn, hard-light, soft-light, difference, exclusion, hue, saturation, color, luminosity.
cursor Escolhe o cursor do ponteiro. auto, default, pointer, crosshair, move, text, wait, help, not-allowed, grab, grabbing, zoom-in, zoom-out, url().
pointer-events Define se o elemento recebe eventos do ponteiro. auto: comportamento normal; none: ignora eventos e permite que o elemento abaixo receba-os.
user-select Permite ou bloqueia seleção. auto, none, text, all, contain.
scroll-behavior Define o movimento da rolagem. auto: imediato; smooth: suave.
scroll-snap-type Ativa o encaixe de rolagem. none; eixo x, y, block, inline ou both; rigor: mandatory ou proximity.
scroll-snap-align Define o ponto de encaixe do elemento filho. none, start, center, end; aceita um eixo lógico ou ambos.
overscroll-behavior Controla rolagem além dos limites. auto, contain, none. Pode receber valores separados para os eixos X e Y.
resize Permite redimensionamento manual. none, both, horizontal, vertical, block, inline.
appearance Controla a aparência nativa dos controles. none, auto, textfield, button, menulist, checkbox, radio, searchfield, slider-horizontal.
accent-color Personaliza controles nativos. auto usa a cor do sistema ou uma cor CSS como #2563eb, rgb() ou hsl().
caret-color Define a cor do cursor em edição. auto ou uma cor CSS válida.

Seletores, cascata e variáveis

Propriedade / conceito Para que serve Exemplo para copiar
Seletor de elemento Seleciona todas as tags correspondentes. p { color: #222222; }
Seletor de classe Seleciona elementos que possuem uma classe. .card { border-radius: 8px; }
Seletor de id Seleciona um elemento pelo identificador único. #inicio { scroll-margin-top: 24px; }
Seletor universal Seleciona todos os elementos. * { box-sizing: border-box; }
Combinadores Seleciona descendentes, filhos, irmãos próximos ou seguintes. nav > a + a { margin-left: 12px; }
Pseudoclasses Aplica estilos conforme estado ou posição. button:hover, button:focus-visible { outline: 2px solid currentColor; }
Pseudoelementos Estiliza partes virtuais do elemento. p::first-line { font-weight: bold; }
Variáveis CSS Cria valores reutilizáveis com var(). :root { --cor-principal: #2563eb; } .botao { background: var(--cor-principal); }
@media Aplica regras conforme características da tela. @media (max-width: 768px) { .card { padding: 16px; } }
@supports Aplica regras apenas quando o navegador suporta um recurso. @supports (display: grid) { .layout { display: grid; } }
@container Cria estilos responsivos conforme o tamanho de um contêiner. @container (min-width: 600px) { .painel { display: grid; } }
@keyframes Define os estados de uma animação. @keyframes aparecer { from { opacity: 0; } to { opacity: 1; } }
