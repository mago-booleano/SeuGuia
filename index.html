Instalação do npm

Para permitir a execução de scripts no PowerShell do VS Code:

Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned

Verificando versões

Mostra a versão do Node.js instalada:

node -v

Mostra a versão do npm instalada:

npm -v

Mostra a versão completa do executável do npm:

npm --version

Exibe informações detalhadas sobre o ambiente Node.js e npm:

npm config list

Abre o painel de configuração do npm no navegador:

npm config list --json

Gerenciamento de pacotes

  • Instala dependências do projeto:
    npm install
  • Instala um pacote:
    npm install pacote
  • Instala um pacote como dependência de desenvolvimento:
    npm install -D pacote
  • Remove um pacote:
    npm uninstall pacote
  • Lista os pacotes instalados:
    npm list
  • Mostra os scripts disponíveis do projeto:
    npm run
  • Executa um pacote temporário sem instalação global:
    npx
  • Instala um pacote como dependência normal:
    npm install express --save
  • Instala um pacote como dependência global:
    npm install -g typescript
  • Instala uma versão específica de um pacote:
    npm install react@18.3.1
  • Instala a versão mais recente dentro da faixa aceita:
    npm install react@latest
  • Remove um pacote de todas as dependências:
    npm uninstall express
  • Pesquisa pacotes disponíveis no registro npm:
    npm search express
  • Exibe informações sobre um pacote:
    npm view react description
  • Instala todas as dependências do package.json:
    npm install --package-lock-only
  • Limpa pacotes não referenciados por dependências:
    npm prune
  • Reinstala dependências ausentes ou corrompidas:
    npm rebuild
  • Executa uma versão temporária de uma ferramenta:
    npx prettier --write .
  • Mostra os pacotes desatualizados em formato detalhado:
    npm outdated --long

Scripts do projeto

  • Executa o script de inicialização, se definido no package.json:
    npm start
  • Executa o script de desenvolvimento, se definido no package.json:
    npm run dev
  • Executa os testes definidos no projeto:
    npm test
  • Gera a versão de produção, se houver esse script:
    npm run build
  • Executa o script com argumentos adicionais:
    npm run dev -- --host 0.0.0.0
  • Executa um script de forma silenciosa:
    npm run build --silent
  • Executa todos os scripts cujo nome começa com "test":
    npm run test:unit
  • Mostra o diretório usado por pacotes executáveis locais:
    npx which vite

Instalação e atualização

  • Instala exatamente as versões do package-lock.json:
    npm ci
    Requer um arquivo package-lock.json ou npm-shrinkwrap.json.
  • Atualiza dependências dentro das versões permitidas no package.json:
    npm update
  • Mostra dependências com versões mais recentes disponíveis:
    npm outdated
  • Lista apenas as dependências diretas do projeto:
    npm list --depth=0
  • Atualiza apenas um pacote específico:
    npm update react
  • Atualiza todas as dependências de desenvolvimento:
    npm update --save-dev
  • Corrige vulnerabilidades incluindo mudanças compatíveis:
    npm audit fix --force
    Use com cuidado: pode gerar mudanças incompatíveis.
  • Gera um relatório JSON da auditoria:
    npm audit --json
  • Limpa o cache global do npm:
    npm cache clean --force
  • Mostra o tamanho do diretório de cache:
    npm cache size
  • Lista os usuários publicados no npm:
    npm whoami
  • Publica o pacote atual no registro configurado:
    npm publish
  • Remove uma versão publicada do pacote:
    npm unpublish nome-do-pacote@1.0.0
  • Executa o npm em modo diagnóstico:
    npm doctor

Auditoria e manutenção

  • Verifica vulnerabilidades conhecidas nas dependências:
    npm audit
  • Tenta corrigir vulnerabilidades sem mudanças incompatíveis:
    npm audit fix
    Pode atualizar o package-lock.json. Revise as alterações antes de enviar o projeto.
  • Verifica a integridade do cache local do npm:
    npm cache verify

Comandos Git

Execute os comandos no terminal, dentro da pasta do projeto. Troque os valores de exemplo pelos seus dados.

  • Confere se o Git está instalado:
    git --version
  • Configura seu nome para os commits:
    git config --global user.name "Seu Nome"
  • Configura seu e-mail para os commits:
    git config --global user.email "voce@exemplo.com"
  • Inicia um repositório Git na pasta atual:
    git init
  • Baixa uma cópia de um repositório remoto:
    git clone URL_DO_REPOSITORIO
    Substitua pelo endereço HTTPS ou SSH do repositório.
  • Mostra arquivos modificados e o estado do repositório:
    git status
  • Prepara um arquivo para o próximo commit:
    git add nome-do-arquivo
  • Prepara todas as alterações da pasta:
    git add .
  • Registra as alterações preparadas:
    git commit -m "Descreva a alteracao"
  • Exibe o histórico resumido de commits:
    git log --oneline
  • Mostra alterações ainda não preparadas para commit:
    git diff
  • Mostra alterações já preparadas para commit:
    git diff --staged
  • Lista as branches locais:
    git branch
  • Cria uma branch e muda para ela:
    git switch -c nome-da-branch
  • Muda para uma branch existente:
    git switch nome-da-branch
  • Lista os repositórios remotos configurados:
    git remote -v
  • Conecta o projeto a um repositório remoto:
    git remote add origin URL_DO_REPOSITORIO
    Use quando o projeto ainda não tem um remoto chamado origin.
  • Envia a branch atual e configura o upstream:
    git push -u origin main
    Troque main pelo nome da sua branch, se necessário.
  • Envia novos commits para o remoto:
    git push
  • Baixa e integra alterações da branch remota:
    git pull origin main
    Confirme o nome da branch antes de executar.
  • Baixa informações do remoto sem integrar alterações:
    git fetch
  • Guarda temporariamente alterações ainda não commitadas:
    git stash
  • Restaura as alterações guardadas mais recentemente:
    git stash pop
  • Descarta alterações locais de um arquivo:
    git restore nome-do-arquivo
    Atenção: remove as alterações locais não commitadas desse arquivo.
  • Remove o rastreamento de um arquivo sem apagá-lo do disco:
    git rm --cached nome-do-arquivo
  • Move ou renomeia um arquivo mantendo o histórico:
    git mv antigo.txt novo.txt
  • Mostra o histórico completo com ramificações:
    git log --oneline --graph --decorate --all
  • Mostra os autores e linhas alteradas em um arquivo:
    git blame nome-do-arquivo
  • Localiza o commit que introduziu uma mudança:
    git bisect start
  • Marca o commit atual como bom durante a busca:
    git bisect good
  • Marca o commit atual como ruim durante a busca:
    git bisect bad
  • Finaliza a busca por regressão:
    git bisect reset
  • Exclui uma branch local já integrada:
    git branch -d nome-da-branch
  • Exclui uma branch local mesmo não integrada:
    git branch -D nome-da-branch
  • Exclui uma branch no repositório remoto:
    git push origin --delete nome-da-branch
  • Baixa uma branch remota para uma branch local:
    git switch --track origin/nome-da-branch
  • Mescla uma branch na branch atual:
    git merge nome-da-branch
  • Envia uma branch específica para o remoto:
    git push origin nome-da-branch
  • Busca alterações e atualiza branches remotas:
    git fetch --prune
  • Reaplica commits sobre a branch atual:
    git rebase main
  • Continua um rebase após resolver conflitos:
    git rebase --continue
  • Cancela um rebase em andamento:
    git rebase --abort
  • Copia um commit específico para a branch atual:
    git cherry-pick HASH_DO_COMMIT
  • Cria uma cópia temporária das alterações locais:
    git stash push -m "descricao das alterações"
  • Lista todas as cópias temporárias:
    git stash list
  • Aplica uma stash sem removê-la da lista:
    git stash apply stash@{0}
  • Apaga uma stash específica:
    git stash drop stash@{0}
  • Desfaz um commit criando outro commit reverso:
    git revert HASH_DO_COMMIT
  • Cria uma tag anotada para uma versão:
    git tag -a v1.0.0 -m "Versão 1.0.0"
  • Lista todas as tags do projeto:
    git tag --list
  • Envia todas as tags para o repositório remoto:
    git push origin --tags
  • Desfaz o staging de todos os arquivos:
    git reset
  • Mostra commits ainda não enviados ao remoto:
    git log origin/main..HEAD
  • Abre uma interface gráfica de resolução de conflitos:
    git mergetool

Atributos HTML

Os atributos ficam na tag de abertura, dentro dos sinais < >. Por exemplo, em <a href="...">, href indica o destino do link. Copie cada exemplo e substitua os valores de demonstração pelos seus.

Elemento / atributo Para que serve Exemplo para copiar
Link · href Define o endereço de destino de um link. <a href="https://developer.mozilla.org/">Documentação HTML</a>
Link · href interno Leva a uma seção da mesma página que tenha o id indicado. <a href="#contato">Ir para contato</a>
Link · target e rel Abre em outra aba e evita que a página aberta controle a página de origem. <a href="https://developer.mozilla.org/" target="_blank" rel="noopener noreferrer">Abrir documentação</a>
Link · rel="nofollow" Indica aos mecanismos de busca que o site não está endossando o destino. <a href="https://exemplo.com/" rel="nofollow">Link externo</a>
Link · mailto e tel Cria links para iniciar um e-mail ou uma ligação. <a href="mailto:contato@exemplo.com">Enviar e-mail</a> <a href="tel:+551155555555">Ligar</a>
Link · download Sugere baixar o arquivo indicado pelo link. <a href="arquivos/guia.pdf" download>Baixar guia</a>
link · rel e href Carrega um arquivo CSS externo no documento. <link rel="stylesheet" href="estilos.css">
img · src e alt Define o arquivo da imagem e um texto alternativo descritivo. <img src="foto.jpg" alt="Descrição da imagem">
img · loading Adia o carregamento de imagens que estão fora da tela. <img src="paisagem.jpg" alt="Paisagem" loading="lazy" width="800" height="600">
script · src e defer Carrega um arquivo JavaScript externo sem bloquear a leitura do HTML. <script src="app.js" defer></script>
form · action e method Define para onde e como os dados do formulário serão enviados. <form action="/cadastro" method="post">...</form>
label · for e input · id Associa o rótulo ao campo correspondente. <label for="email">E-mail</label> <input id="email" type="email">
input · type Escolhe o tipo de campo e os recursos de entrada apropriados. <input type="email" name="email">
input · name e value Define o nome enviado ao servidor e o valor do campo. <input type="text" name="cidade" value="São Paulo">
input · placeholder Exibe uma dica curta; não substitui o elemento label. <input type="search" placeholder="Buscar...">
required e autocomplete Exige preenchimento e permite ao navegador sugerir dados salvos. <input type="email" name="email" autocomplete="email" required>
button · type Escolhe se o botão envia o formulário ou executa outra ação. <button type="submit">Enviar</button> <button type="button">Abrir</button>
Atributos globais · id e class Identifica um elemento e agrupa elementos para aplicar estilos ou scripts. <section id="contato" class="secao">Contato</section>
Atributos globais · title e lang Fornece informação adicional e indica o idioma do conteúdo. <p lang="pt-BR" title="Informação adicional">Olá!</p>
Atributo global · data-* Guarda dados personalizados no elemento para uso em scripts. <button data-produto-id="42">Adicionar</button>
Acessibilidade · aria-label Dá um nome acessível quando o texto visível não descreve o controle. <button type="button" aria-label="Fechar menu">×</button>
Atributos globais · style e hidden Aplica CSS direto ao elemento e pode ocultá-lo da página. <p style="color: red" hidden>Aviso oculto</p>
Atributos globais · tabindex Controla a posição do elemento na navegação por teclado ou permite que ele receba foco. <div tabindex="0">Painel focável</div>
Atributos globais · contenteditable Permite que o usuário edite o conteúdo do elemento diretamente. <p contenteditable="true" spellcheck="true">Edite este texto</p>
Atributos globais · draggable e dropzone Permite arrastar o elemento; dropzone está obsoleto e não deve ser usado em código novo. <div draggable="true">Item arrastável</div>
Atributos globais · dir e translate Define a direção do texto e controla se o conteúdo pode ser traduzido automaticamente. <p dir="ltr" translate="no">Texto original</p>
Atributos globais · inert Impede interação, foco e navegação pelos elementos dentro da região marcada. <section inert><button>Indisponível</button></section>
Atributos globais · popover Transforma um elemento em uma camada popover controlada pelo navegador. <button popovertarget="aviso">Abrir aviso</button><div id="aviso" popover>Mensagem</div>
Atributos globais · autocapitalize e enterkeyhint Sugere capitalização e o rótulo da tecla Enter em teclados móveis. <input type="text" autocapitalize="words" enterkeyhint="next">
Atributos globais · spellcheck e autocorrect Ativa a correção ortográfica e, quando suportado, a correção automática. <textarea spellcheck="true" autocorrect="on"></textarea>
Atributo global · nonce Autoriza scripts ou estilos específicos em páginas que usam Content Security Policy. <script nonce="TOKEN-SEGURO">console.log("Permitido")</script>
Atributo global · role Define um papel ARIA quando a semântica nativa do elemento não representa a interface. <div role="status" aria-live="polite">Alteração salva</div>
Acessibilidade · aria-labelledby e aria-describedby Associa nomes e descrições acessíveis a elementos por meio de outros ids. <h2 id="titulo">Preferências</h2><p id="ajuda">Escolha uma opção.</p><button aria-labelledby="titulo" aria-describedby="ajuda">Continuar</button>
Acessibilidade · aria-expanded e aria-controls Indica se uma região está aberta e qual elemento ela controla. <button aria-expanded="false" aria-controls="menu">Menu</button><div id="menu" hidden>Links</div>
Acessibilidade · aria-current Marca o item atual em navegação, etapas ou uma lista de opções. <a href="/guia" aria-current="page">Guia atual</a>
Acessibilidade · aria-pressed e aria-checked Comunica estados pressionados ou selecionados em controles personalizados. <button aria-pressed="true">Favorito</button><div role="checkbox" aria-checked="false" tabindex="0">Aceito</div>
Acessibilidade · aria-hidden Remove um elemento decorativo ou redundante da árvore de acessibilidade. <span aria-hidden="true">★</span>Favorito
Atributos · meta charset e viewport Define a codificação dos caracteres e a largura adequada em dispositivos móveis. <meta charset="UTF-8"><meta name="viewport" content="width=device-width, initial-scale=1">
Atributos · meta description e theme-color Fornece descrição para resultados de busca e cor da interface do navegador. <meta name="description" content="Guia de desenvolvimento web"><meta name="theme-color" content="#1b1b1b">
Atributos · meta http-equiv Configura instruções HTTP diretamente no documento, como charset ou proteção de conteúdo. <meta http-equiv="Content-Security-Policy" content="default-src 'self'">
Link · rel variants Relaciona recursos como ícone, autor, pré-carregamento ou descrição do documento. <link rel="icon" href="favicon.svg" type="image/svg+xml"><link rel="preload" href="fonte.woff2" as="font" type="font/woff2" crossorigin>
Link · crossorigin e integrity Controla o acesso entre origens e verifica a integridade de recursos externos. <script src="https://cdn.exemplo.com/lib.js" integrity="sha384-HASH" crossorigin="anonymous"></script>
Script · async e type="module" Executa scripts assíncronos ou habilita módulos JavaScript modernos. <script src="app.js" async></script><script type="module" src="main.js"></script>
Img · srcset e sizes Oferece versões da imagem conforme densidade de pixels ou largura disponível. <img src="foto-600.jpg" srcset="foto-600.jpg 600w, foto-1200.jpg 1200w" sizes="(max-width: 600px) 100vw, 600px" alt="Paisagem">
Img · decoding e fetchpriority Sugere a estratégia de decodificação e a prioridade de carregamento da imagem. <img src="capa.jpg" alt="Capa" decoding="async" fetchpriority="high">
Media · controlslist e crossorigin Personaliza controles visíveis e configura o carregamento de mídia entre origens. <video src="video.mp4" controls controlslist="nodownload" crossorigin="anonymous"></video>
Media · autoplay, loop, muted e preload Configura reprodução automática, repetição, áudio inicial e estratégia de pré-carregamento. <video src="apresentacao.mp4" autoplay muted loop playsinline preload="metadata"></video>
Media · poster e track attributes Define uma imagem antes da reprodução e configura legendas em WebVTT. <video poster="capa.jpg" controls><track src="legendas.vtt" kind="captions" srclang="pt-BR" label="Português" default></video>
Form · enctype e novalidate Define a codificação dos dados enviados e permite desativar a validação automática. <form action="/upload" method="post" enctype="multipart/form-data" novalidate></form>
Form · accept-charset e target Sugere codificações aceitas e define onde o resultado do envio será exibido. <form action="/busca" method="get" accept-charset="UTF-8" target="_blank"></form>
Input · min, max e step Define limites numéricos ou de data e o intervalo entre valores válidos. <input type="number" name="quantidade" min="1" max="10" step="1" value="1">
Input · minlength, maxlength e pattern Limita o tamanho do texto e exige correspondência com uma expressão regular. <input type="text" name="codigo" minlength="4" maxlength="8" pattern="[A-Z0-9]+">
Input · multiple e accept Permite vários arquivos ou valores e limita os tipos aceitos pelo seletor. <input type="file" name="arquivos" accept="image/png,image/jpeg" multiple>
Input · disabled, readonly e checked Desativa o campo, impede edição ou marca uma opção inicialmente selecionada. <input type="text" value="Somente leitura" readonly><input type="checkbox" checked disabled>
Input · list e datalist Relaciona o campo de texto a uma lista de sugestões predefinidas. <input list="cores"><datalist id="cores"><option value="Azul"></datalist>
Input · inputmode e autocapitalize Sugere um teclado móvel adequado e o comportamento de letras maiúsculas. <input type="text" inputmode="numeric" pattern="[0-9]*" autocapitalize="off">
Select · multiple, size e optgroup Permite várias opções, define quantidade visível e agrupa escolhas relacionadas. <select name="estado" multiple size="3"><optgroup label="Sudeste"><option value="sp">São Paulo</option></optgroup></select>
Textarea · cols, rows e wrap Define largura, altura e como as quebras de linha são enviadas ao servidor. <textarea name="mensagem" cols="40" rows="5" wrap="soft"></textarea>
Button · form, formaction e formmethod Permite associar ou enviar o botão por outro formulário e com outro método. <button type="submit" form="cadastro" formaction="/rascunho" formmethod="post">Salvar rascunho</button>
Button · formnovalidate e value Evita a validação neste envio e informa um valor associado ao botão. <button type="submit" name="acao" value="cancelar" formnovalidate>Cancelar</button>
Details · open e name Mantém o conteúdo aberto inicialmente e permite criar um grupo exclusivo de disclosures. <details name="faq" open><summary>Pergunta</summary><p>Resposta</p></details>
Dialog · open e method="dialog" Mantém o diálogo visível ou permite que um formulário o feche sem JavaScript. <dialog open><form method="dialog"><button value="ok">Fechar</button></form></dialog>
Table · colspan e rowspan Faz uma célula ocupar várias colunas ou várias linhas da tabela. <td colspan="2" rowspan="2">Conteúdo unido</td>
Table · scope e headers Associa cabeçalhos a linhas ou colunas e vincula células a ids específicos. <th id="nome" scope="col">Nome</th><td headers="nome">Ana</td>
Time · datetime Fornece uma representação legível por máquinas para data, hora ou duração. <time datetime="2026-11-19T14:30:00-03:00">19 de novembro às 14:30</time>
Meter · low, high e optimum Define faixas de avaliação dentro da medida conhecida. <meter min="0" max="100" low="30" high="70" optimum="100" value="80">80%</meter>

Tags HTML: descrições e exemplos

  • <a>: link para outra página, arquivo ou seção.
    <a href="https://exemplo.com">Visitar site</a>
  • <article>: conteúdo independente, como uma notícia ou publicação.
    <article><h2>Notícia</h2><p>Texto</p></article>
  • <aside>: conteúdo complementar ao conteúdo principal.
    <aside>Leia também</aside>
  • <body>: corpo da página, onde fica o conteúdo visível.
    <body><main>Conteúdo</main></body>
  • <button>: botão que pode ser acionado pelo usuário.
    <button type="button">Salvar</button>
  • <code>: trecho de código.
    <code>npm test</code>
  • <div>: contêiner genérico para agrupar conteúdo.
    <div class="grupo">Conteúdo</div>
  • <footer>: rodapé de uma página ou seção.
    <footer>Fim da página</footer>
  • <form>: formulário para envio de informações.
    <form action="/enviar" method="post">Campos</form>
  • <h1>: título principal de uma seção.
    <h1>Título principal</h1>
  • <h2>: título de segundo nível.
    <h2>Uma seção</h2>
  • <h3>: título de terceiro nível.
    <h3>Um tópico</h3>
  • <head>: metadados e configurações do documento HTML.
    <head><title>Minha página</title></head>
  • <header>: cabeçalho de uma página ou seção.
    <header><h1>Meu site</h1></header>
  • <html>: elemento raiz de um documento HTML.
    <html lang="pt-BR"><body><main>Conteúdo do documento</main></body></html>
  • <img>: imagem incorporada ao documento.
    <img src="foto.jpg" alt="Descrição da foto">
  • <input>: campo de entrada de dados.
    <input type="email" placeholder="Seu e-mail">
  • <label>: rótulo associado a um campo de formulário.
    <label for="email">E-mail</label>
  • <li>: item de uma lista.
    <li>Item da lista</li>
  • <link>: referência a um recurso externo, geralmente uma folha de estilos.
    <link rel="stylesheet" href="estilos.css">
  • <main>: conteúdo principal do documento.
    <main>Conteúdo principal</main>
  • <nav>: grupo de links de navegação.
    <nav><a href="/">Início</a></nav>
  • <ol>: lista ordenada.
    <ol><li>Primeiro passo</li></ol>
  • <option>: opção disponível em uma lista de seleção.
    <option value="br">Brasil</option>
  • <p>: parágrafo de texto.
    <p>Um parágrafo.</p>
  • <script>: código JavaScript ou referência a um arquivo de script.
    <script src="app.js"></script>
  • <section>: seção temática do documento.
    <section><h2>Sobre</h2><p>Texto</p></section>
  • <select>: lista de opções selecionáveis.
    <select><option>Brasil</option></select>
  • <small>: texto complementar ou apresentado em tamanho menor.
    <small>Observação</small>
  • <span>: contêiner genérico em linha.
    <span class="destaque">Texto</span>
  • <strong>: texto de grande importância, normalmente exibido em negrito.
    <strong>Importante</strong>
  • <style>: regras CSS incorporadas ao documento.
    <style>p { color: blue; }</style>
  • <table>: tabela de dados.
    <table><tr><th>Nome</th></tr></table>
  • <td>: célula de dados de uma tabela.
    <td>Ana</td>
  • <textarea>: campo de texto com várias linhas.
    <textarea name="mensagem"></textarea>
  • <th>: célula de cabeçalho de uma tabela.
    <th scope="col">Nome</th>
  • <title>: título do documento exibido na aba do navegador.
    <title>Minha página</title>
  • <tr>: linha de uma tabela.
    <tr><td>Ana</td></tr>
  • <ul>: lista não ordenada.
    <ul><li>Item</li></ul>
  • <br>: quebra de linha dentro do texto.
    <p>Primeira linha<br>Segunda linha</p>
  • <hr>: separador temático ou linha horizontal.
    <p>Introdução</p><hr><p>Detalhes</p>
  • <em>: dá ênfase semântica a uma palavra ou frase.
    <p>Este recurso é <em>importante</em>.</p>
  • <b>: destaca texto visualmente sem indicar importância semântica.
    <p><b>Aviso:</b> confira os dados.</p>
  • <i>: representa texto alternativo, como um termo técnico ou nome.
    <p>O termo <i>fallback</i> significa alternativa.</p>
  • <mark>: realça parte do texto.
    <p>A <mark>palavra destacada</mark> aparece realçada.</p>
  • <q>: inclui uma citação curta em linha.
    <p>Ela disse <q>Vamos começar</q>.</p>
  • <blockquote>: inclui uma citação longa em bloco.
    <blockquote>Texto citado de outra fonte.</blockquote>
  • <pre>: preserva espaços e quebras de linha.
    <pre>linha 1 linha 2</pre>
  • <dl>, <dt> e <dd>: definem uma lista de termos e descrições.
    <dl><dt>npm</dt><dd>Gerenciador de pacotes</dd></dl>
  • <figure> e <figcaption>: associam uma mídia a sua legenda.
    <figure><img src="foto.jpg" alt="Foto"><figcaption>Legenda</figcaption></figure>
  • <picture> e <source>: oferecem versões de imagem por tamanho ou formato.
    <picture><source srcset="foto.webp" type="image/webp"><img src="foto.jpg" alt="Foto"></picture>
  • <video>: incorpora vídeo com controles de reprodução.
    <video src="video.mp4" controls>Vídeo indisponível.</video>
  • <audio>: incorpora áudio com controles de reprodução.
    <audio src="musica.mp3" controls>Áudio indisponível.</audio>
  • <source>: fornece alternativas dentro de picture, video ou audio.
    <video controls><source src="video.webm" type="video/webm"></video>
  • <iframe>: incorpora outro documento HTML em uma página.
    <iframe src="pagina.html" title="Página incorporada"></iframe>
  • <canvas>: área usada por JavaScript para desenhar gráficos.
    <canvas id="tela" width="300" height="150"></canvas>
  • <svg>: incorpora gráficos vetoriais escaláveis.
    <svg width="100" height="100"><circle cx="50" cy="50" r="40" fill="blue"/></svg>
  • <details> e <summary>: criam conteúdo expansível sem JavaScript.
    <details><summary>Mostrar detalhes</summary><p>Conteúdo oculto</p></details>
  • <dialog>: representa uma caixa de diálogo modal ou não modal.
    <dialog open><p>Mensagem</p></dialog>
  • <meter>: mostra uma medida dentro de um intervalo conhecido.
    <meter min="0" max="100" value="75">75%</meter>
  • <progress>: indica progresso de uma tarefa.
    <progress value="60" max="100">60%</progress>
  • <time>: representa uma data ou hora legível por máquinas.
    <time datetime="2026-11-18">18 de novembro de 2026</time>
  • <address>: apresenta informações de contato do autor ou organização.
    <address>Contato: contato@exemplo.com</address>
  • <fieldset> e <legend>: agrupam campos relacionados em um formulário.
    <fieldset><legend>Contato</legend><input name="nome"></fieldset>
  • <datalist>: fornece sugestões para um campo de texto.
    <input list="cidades"><datalist id="cidades"><option value="São Paulo"></datalist>
  • <textarea>: campo com várias linhas e rótulo associado.
    <label for="msg">Mensagem</label><textarea id="msg" name="mensagem" rows="4"></textarea>
  • <button>: tipos importantes são submit, reset e button.
    <form><button type="submit">Enviar</button><button type="reset">Limpar</button></form>
  • <table>, <thead>, <tbody> e <tfoot>: organizam uma tabela completa.
    <table><thead><tr><th>Nome</th></tr></thead><tbody><tr><td>Ana</td></tr></tbody></table>
  • <abbr>: indica uma abreviação ou sigla.
    <abbr title="HyperText Markup Language">HTML</abbr>
  • <cite>: identifica o título de uma obra citada.
    <p>Leia <cite>Guia HTML</cite>.</p>
  • <data>: associa um valor legível por máquina ao texto exibido.
    <data value="produto-10">Produto A</data>
  • <samp>: representa uma saída produzida por um programa.
    <p>Saída: <samp>Arquivo salvo</samp></p>
  • <kbd>: representa entrada feita pelo teclado.
    <p>Pressione <kbd>Ctrl</kbd> + <kbd>S</kbd>.</p>
  • <map> e <area>: criam regiões clicáveis em uma imagem.
    <img src="mapa.jpg" usemap="#mapa"><map name="mapa"><area shape="rect" coords="0,0,100,100" href="brasil.html"></map>
  • <meta>: fornece metadados sobre o documento, como codificação e responsividade.
    <meta charset="UTF-8"><meta name="viewport" content="width=device-width, initial-scale=1">
  • <base>: define uma URL base para links e recursos relativos do documento.
    <base href="https://exemplo.com/docs/" target="_blank">
  • <noscript>: mostra conteúdo alternativo quando JavaScript está desativado.
    <noscript><p>Ative o JavaScript para usar esta página.</p></noscript>
  • <template>: mantém HTML inativo para criação posterior por JavaScript.
    <template id="item"><li>Novo item</li></template>
  • <slot>: reserva uma posição onde conteúdo externo pode ser inserido em um Web Component.
    <slot name="titulo">Título padrão</slot>
  • <wbr>: sugere uma quebra de linha segura em palavras longas.
    <p>supercalifragilistic<wbr>expialidocious</p>
  • <ins>: marca texto inserido em uma revisão.
    <p>Novo preço: <ins datetime="2026-11-19">R$ 79,90</ins></p>
  • <del>: marca texto removido em uma revisão.
    <p>Preço anterior: <del datetime="2026-11-19">R$ 99,90</del></p>
  • <bdi>: isola texto cuja direção pode diferir da direção do documento.
    <li>Usuário: <bdi>محمد</bdi></li>
  • <bdo>: substitui explicitamente a direção do texto.
    <bdo dir="rtl">texto da direita para a esquerda</bdo>
  • <ruby>, <rt> e <rp>: fornecem anotações de pronúncia ou leitura em texto.
    <ruby>漢 <rp>(</rp><rt>kan</rt><rp>)</rp></ruby>
  • <track>: adiciona legendas, descrições ou capítulos a áudio e vídeo.
    <video controls src="video.mp4"><track kind="captions" src="legendas.vtt" srclang="pt" label="Português" default></video>
  • <caption>, <colgroup> e <col>: nomeiam e formatam colunas de tabelas.
    <table><caption>Vendas</caption><colgroup><col span="1"></colgroup></table>
  • <object>: incorpora recursos externos como documentos ou mídias.
    <object data="catalogo.pdf" type="application/pdf" width="600" height="400">PDF indisponível.</object>
  • <embed>: incorpora um recurso externo no documento.
    <embed type="image/svg+xml" src="imagem.svg" width="300" height="200">
  • <param>: fornece parâmetros para objetos incorporados legados.
    <object data="arquivo.swf" type="application/x-shockwave-flash"><param name="autoplay" value="true"></object>
