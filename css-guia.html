Estrutura básica

.seletor {
    propriedade: valor;
}

Uma propriedade define o que será alterado. Um valor define como será alterado. A declaração inteira termina com ponto e vírgula.

Toda propriedade aceita os valores globais initial, inherit, unset, revert e revert-layer. Nem toda combinação existe para toda propriedade.

1. Seletores e conceitos básicos

all
Reseta todas as propriedades herdáveis e não herdáveis para o valor informado. 
artigo { all: unset; }
display
block ocupa uma linha; inline segue o fluxo; inline-block combina os dois; none remove da renderização; flex, grid, contents. 
.menu { display: flex; }
.aviso { display: none; }
box-sizing
content-box calcula padding e borda fora da largura. border-box inclui padding e borda na largura. 
* { box-sizing: border-box; }
overflow
visible, hidden, clip, scroll e auto. Use overflow-x e overflow-y separadamente. 
.caixa { overflow: hidden; }
.tabela { overflow-x: auto; }

2. Cores e tipagem de valores

Nomeada

color: red;
color: rebeccapurple;
color: transparent;

Hexadecimal

color: #39ff14;
color: #39f;
color: #39ff1480;

Os últimos dois dígitos representam alfa.

RGB e HSL

color: rgb(57 255 20);
color: rgb(57 255 20 / 50%);
color: hsl(112 100% 54%);

Espaços modernos

color: oklch(70% 0.15 145);
color: color-mix(in srgb, red 30%, blue);

3. Box model

width / height
auto, comprimentos, porcentagens, min(), max(), clamp(), fit-content. 
.container { width: min(100%, 1120px); }
.titulo { font-size: clamp(2rem, 5vw, 4rem); }
min-width / max-width
Limitam o crescimento ou a redução da largura. 
.cartao { min-width: 280px; max-width: 600px; }
padding
Define o espaçamento interno. Um valor aplica todos; dois usam vertical/horizontal; três usam superior/horizontal/inferior; quatro usam superior/direita/inferior/esquerda. 
padding: 20px;
padding: 10px 20px;
padding: 10px 20px 30px 40px;
margin
Define o espaçamento externo. Aceita comprimentos, porcentagens e auto. 
.container { margin: 50px auto; }
.cartao { margin-bottom: 20px; }
border
Forma abreviada de largura, estilo e cor. 
border: 2px solid #39ff14;
border-left: 4px dashed red;
border: 0;
border-radius
Arredonda um ou vários cantos usando comprimentos ou porcentagens. 
border-radius: 12px;
border-radius: 50%;
border-top-left-radius: 30px;
Exemplo visual
Padding interno, borda verde e sombra externa.

5. Layout: posicionamento, flexbox e grid

position
static segue o fluxo; relative se desloca sem sair dele; absolute usa o ancestral posicionado; fixed usa a janela; sticky fixa ao atingir o limite. 
.menu { position: sticky; top: 0; }
.botao-flutuante { position: fixed; right: 24px; bottom: 24px; }
top / right / bottom / left / inset
Controlam deslocamentos e posições. inset: 0 aplica zero aos quatro lados. 
.overlay { position: absolute; inset: 0; }
z-index
Controla a ordem vertical de elementos posicionados. Valores maiores aparecem acima. 
.menu { z-index: 10; }
.fundo { z-index: -1; }

Flexbox

.linha {
    display: flex;
    flex-direction: row;
    justify-content: space-between;
    align-items: center;
    flex-wrap: wrap;
    gap: 12px;
}

.item {
    flex: 1 1 220px;
}

justify-content alinha no eixo principal. align-items alinha no eixo cruzado. flex-grow flex-shrink flex-basis formam flex.

Grid

.grade {
    display: grid;
    grid-template-columns: repeat(2, minmax(0, 1fr));
    gap: 20px;
}

.titulo {
    grid-column: 1 / -1;
}

1fr representa uma fração do espaço disponível. repeat(), minmax() e auto-fit ajudam na responsividade.

7. Transições e animações

transition
Aplica uma mudança suave entre estados. 
.botao {
    transition: color 180ms ease,
                background 180ms ease,
                transform 180ms ease;
}
animation
Executa os estados definidos por @keyframes. 
@keyframes aparecer {
    from { opacity: 0; transform: translateY(16px); }
    to   { opacity: 1; transform: translateY(0); }
}

.card { animation: aparecer 700ms ease-out both; }

Estados e pseudo-classes

a:hover { color: #39ff14; }
button:active { transform: scale(0.98); }
input:focus { outline: 3px solid #39ff14; }
li:first-child { margin-top: 0; }
li:nth-child(2) { color: yellow; }
button:disabled { opacity: 0.5; }

8. Responsividade e acessibilidade visual

@media
Aplica estilos conforme o tamanho ou preferência do dispositivo. 
@media (max-width: 700px) {
    .container { padding: 12px; }
}

@media (prefers-reduced-motion: reduce) {
    * { animation: none !important; transition: none !important; }
}
@container
Aplica estilos conforme o tamanho de um contêiner. 
.cartoes { container-type: inline-size; }

@container (max-width: 600px) {
    .cartao { width: 100%; }
}
:has()
Seleciona um elemento com base em seus filhos. 
.formulario:has(input:invalid) {
    border-color: red;
}
outline
É usada principalmente para indicar foco. Não ocupar espaço como borda. 
a:focus-visible {
    outline: 3px solid #39ff14;
    outline-offset: 3px;
}

9. Mais propriedades explicadas com exemplos

As propriedades são as “instruções” do CSS: cada uma controla uma parte visual ou de comportamento do elemento.

font-weight
Define a espessura das letras. 400 costuma ser normal e 700 costuma ser negrito. A fonte escolhida precisa ter os pesos disponíveis. 
.texto-normal { font-weight: 400; }
.titulo { font-weight: 700; }
line-height
Controla a distância vertical entre linhas. Um número sem unidade é multiplicado pelo tamanho da fonte; em parágrafos, normalmente melhora a leitura. 
p { font-size: 16px; line-height: 1.6; }
max-width
Limita o quanto um elemento pode crescer. Muito útil para impedir que linhas de texto fiquem longas demais. 
.artigo {
    width: 100%;
    max-width: 720px;
    margin-inline: auto;
}
gap
Cria espaço entre itens de flexbox ou grid sem adicionar margem aos próprios itens. 
.cartoes {
    display: grid;
    grid-template-columns: repeat(2, 1fr);
    gap: 16px;
}
object-fit
Decide como a imagem ou vídeo se encaixa na caixa. cover preenche cortando o excesso; contain mostra tudo e pode deixar espaços vazios. 
.foto {
    width: 240px;
    height: 160px;
    object-fit: cover;
}
aspect-ratio
Define a proporção entre largura e altura; o navegador calcula uma dimensão automaticamente quando a outra está definida. 
.video {
    width: 100%;
    aspect-ratio: 16 / 9;
}
list-style
Escolhe o marcador ou numeração de uma lista. none remove o marcador visual. 
ul { list-style: square; }
ol { list-style: upper-roman; }
nav ul { list-style: none; }
pointer-events
Controla se o elemento pode receber clique ou outros eventos do ponteiro. Use com cuidado para não bloquear controles importantes. 
.decoracao {
    pointer-events: none;
}
scroll-behavior
Define se a rolagem até uma âncora acontece imediatamente ou suavemente. Respeite a preferência de movimento reduzido do usuário. 
html { scroll-behavior: smooth; }

@media (prefers-reduced-motion: reduce) {
    html { scroll-behavior: auto; }
}
content
Insere conteúdo em pseudo-elementos ::before e ::after. Não use para esconder informação importante do leitor. 
.obrigatorio::after {
    content: " (obrigatório)";
    color: red;
}
cursor
Indica visualmente o que acontece ao apontar para um elemento. pointer é comum em links e botões. 
button { cursor: pointer; }
.bloqueado { cursor: not-allowed; }
Variáveis CSS
Guarde valores reutilizados em propriedades com nomes iniciados por --, e recupere-os com var(). 
:root { --cor-principal: #39ff14; }
button {
    color: var(--cor-principal);
    border-color: var(--cor-principal);
}
Unidades
px é uma medida fixa comum; rem depende da fonte raiz; % depende do contexto; vw/vh dependem da tela; fr divide espaço no Grid. 
.texto { font-size: 1rem; }
.painel { width: 80%; }
.tela { min-height: 100vh; }
.grade { grid-template-columns: 1fr 2fr; }

Seletores CSS básicos

O seletor escolhe quais elementos recebem as propriedades.

p { color: white; }             /* todos os parágrafos */
.aviso { color: yellow; }       /* classe aviso */
#principal { padding: 20px; }   /* id principal */
nav a { text-decoration: none; }/* links dentro de nav */
button:hover { color: green; }  /* botão apontado */
input:focus { outline: 2px solid green; }
