Estrutura básica

.seletor {
    propriedade: valor;
}

Uma propriedade define o que será alterado. Um valor define como será alterado. A declaração inteira termina com ponto e vírgula.

Básicos Cores Box model Texto e fontes Layout Fundos e efeitos Transição e animação Responsividade Mais propriedades Seletores Propriedades e valores
Toda propriedade aceita os valores globais initial, inherit, unset, revert e revert-layer. Nem toda combinação existe para toda propriedade.

1. Seletores e conceitos básicos

all
Reseta todas as propriedades herdáveis e não herdáveis para o valor informado. 
artigo { all: unset; }
display
block ocupa uma linha; inline segue o fluxo; inline-block combina os dois; none remove da renderização; flex, grid, contents. 
.menu { display: flex; }
.aviso { display: none; }
box-sizing
content-box calcula padding e borda fora da largura. border-box inclui padding e borda na largura. 
* { box-sizing: border-box; }
overflow
visible, hidden, clip, scroll e auto. Use overflow-x e overflow-y separadamente. 
.caixa { overflow: hidden; }
.tabela { overflow-x: auto; }

2. Cores e tipagem de valores

Nomeada

color: red;
color: rebeccapurple;
color: transparent;

Hexadecimal

color: #39ff14;
color: #39f;
color: #39ff1480;

Os últimos dois dígitos representam alfa.

RGB e HSL

color: rgb(57 255 20);
color: rgb(57 255 20 / 50%);
color: hsl(112 100% 54%);

Espaços modernos

color: oklch(70% 0.15 145);
color: color-mix(in srgb, red 30%, blue);

3. Box model

width / height
auto, comprimentos, porcentagens, min(), max(), clamp(), fit-content. 
.container { width: min(100%, 1120px); }
.titulo { font-size: clamp(2rem, 5vw, 4rem); }
min-width / max-width
Limitam o crescimento ou a redução da largura. 
.cartao { min-width: 280px; max-width: 600px; }
padding
Define o espaçamento interno. Um valor aplica todos; dois usam vertical/horizontal; três usam superior/horizontal/inferior; quatro usam superior/direita/inferior/esquerda. 
padding: 20px;
padding: 10px 20px;
padding: 10px 20px 30px 40px;
margin
Define o espaçamento externo. Aceita comprimentos, porcentagens e auto. 
.container { margin: 50px auto; }
.cartao { margin-bottom: 20px; }
border
Forma abreviada de largura, estilo e cor. 
border: 2px solid #39ff14;
border-left: 4px dashed red;
border: 0;
border-radius
Arredonda um ou vários cantos usando comprimentos ou porcentagens. 
border-radius: 12px;
border-radius: 50%;
border-top-left-radius: 30px;
Exemplo visual
Padding interno, borda verde e sombra externa.

5. Layout: posicionamento, flexbox e grid

position
static segue o fluxo; relative se desloca sem sair dele; absolute usa o ancestral posicionado; fixed usa a janela; sticky fixa ao atingir o limite. 
.menu { position: sticky; top: 0; }
.botao-flutuante { position: fixed; right: 24px; bottom: 24px; }
top / right / bottom / left / inset
Controlam deslocamentos e posições. inset: 0 aplica zero aos quatro lados. 
.overlay { position: absolute; inset: 0; }
z-index
Controla a ordem vertical de elementos posicionados. Valores maiores aparecem acima. 
.menu { z-index: 10; }
.fundo { z-index: -1; }

Flexbox

.linha {
    display: flex;
    flex-direction: row;
    justify-content: space-between;
    align-items: center;
    flex-wrap: wrap;
    gap: 12px;
}

.item {
    flex: 1 1 220px;
}

justify-content alinha no eixo principal. align-items alinha no eixo cruzado. flex-grow flex-shrink flex-basis formam flex.

Grid

.grade {
    display: grid;
    grid-template-columns: repeat(2, minmax(0, 1fr));
    gap: 20px;
}

.titulo {
    grid-column: 1 / -1;
}

1fr representa uma fração do espaço disponível. repeat(), minmax() e auto-fit ajudam na responsividade.

7. Transições e animações

transition
Aplica uma mudança suave entre estados. 
.botao {
    transition: color 180ms ease,
                background 180ms ease,
                transform 180ms ease;
}
animation
Executa os estados definidos por @keyframes. 
@keyframes aparecer {
    from { opacity: 0; transform: translateY(16px); }
    to   { opacity: 1; transform: translateY(0); }
}

.card { animation: aparecer 700ms ease-out both; }

Estados e pseudo-classes

a:hover { color: #39ff14; }
button:active { transform: scale(0.98); }
input:focus { outline: 3px solid #39ff14; }
li:first-child { margin-top: 0; }
li:nth-child(2) { color: yellow; }
button:disabled { opacity: 0.5; }

8. Responsividade e acessibilidade visual

@media
Aplica estilos conforme o tamanho ou preferência do dispositivo. 
@media (max-width: 700px) {
    .container { padding: 12px; }
}

@media (prefers-reduced-motion: reduce) {
    * { animation: none !important; transition: none !important; }
}
@container
Aplica estilos conforme o tamanho de um contêiner. 
.cartoes { container-type: inline-size; }

@container (max-width: 600px) {
    .cartao { width: 100%; }
}
:has()
Seleciona um elemento com base em seus filhos. 
.formulario:has(input:invalid) {
    border-color: red;
}
outline
É usada principalmente para indicar foco. Não ocupar espaço como borda. 
a:focus-visible {
    outline: 3px solid #39ff14;
    outline-offset: 3px;
}

9. Mais propriedades explicadas com exemplos

As propriedades são as “instruções” do CSS: cada uma controla uma parte visual ou de comportamento do elemento.

font-weight
Define a espessura das letras. 400 costuma ser normal e 700 costuma ser negrito. A fonte escolhida precisa ter os pesos disponíveis. 
.texto-normal { font-weight: 400; }
.titulo { font-weight: 700; }
line-height
Controla a distância vertical entre linhas. Um número sem unidade é multiplicado pelo tamanho da fonte; em parágrafos, normalmente melhora a leitura. 
p { font-size: 16px; line-height: 1.6; }
max-width
Limita o quanto um elemento pode crescer. Muito útil para impedir que linhas de texto fiquem longas demais. 
.artigo {
    width: 100%;
    max-width: 720px;
    margin-inline: auto;
}
gap
Cria espaço entre itens de flexbox ou grid sem adicionar margem aos próprios itens. 
.cartoes {
    display: grid;
    grid-template-columns: repeat(2, 1fr);
    gap: 16px;
}
object-fit
Decide como a imagem ou vídeo se encaixa na caixa. cover preenche cortando o excesso; contain mostra tudo e pode deixar espaços vazios. 
.foto {
    width: 240px;
    height: 160px;
    object-fit: cover;
}
aspect-ratio
Define a proporção entre largura e altura; o navegador calcula uma dimensão automaticamente quando a outra está definida. 
.video {
    width: 100%;
    aspect-ratio: 16 / 9;
}
list-style
Escolhe o marcador ou numeração de uma lista. none remove o marcador visual. 
ul { list-style: square; }
ol { list-style: upper-roman; }
nav ul { list-style: none; }
pointer-events
Controla se o elemento pode receber clique ou outros eventos do ponteiro. Use com cuidado para não bloquear controles importantes. 
.decoracao {
    pointer-events: none;
}
scroll-behavior
Define se a rolagem até uma âncora acontece imediatamente ou suavemente. Respeite a preferência de movimento reduzido do usuário. 
html { scroll-behavior: smooth; }

@media (prefers-reduced-motion: reduce) {
    html { scroll-behavior: auto; }
}
content
Insere conteúdo em pseudo-elementos ::before e ::after. Não use para esconder informação importante do leitor. 
.obrigatorio::after {
    content: " (obrigatório)";
    color: red;
}
cursor
Indica visualmente o que acontece ao apontar para um elemento. pointer é comum em links e botões. 
button { cursor: pointer; }
.bloqueado { cursor: not-allowed; }
Variáveis CSS
Guarde valores reutilizados em propriedades com nomes iniciados por --, e recupere-os com var(). 
:root { --cor-principal: #39ff14; }
button {
    color: var(--cor-principal);
    border-color: var(--cor-principal);
}
Unidades
px é uma medida fixa comum; rem depende da fonte raiz; % depende do contexto; vw/vh dependem da tela; fr divide espaço no Grid. 
.texto { font-size: 1rem; }
.painel { width: 80%; }
.tela { min-height: 100vh; }
.grade { grid-template-columns: 1fr 2fr; }

Seletores CSS básicos

O seletor escolhe quais elementos recebem as propriedades.

p { color: white; }             /* todos os parágrafos */
.aviso { color: yellow; }       /* classe aviso */
#principal { padding: 20px; }   /* id principal */
nav a { text-decoration: none; }/* links dentro de nav */
button:hover { color: green; }  /* botão apontado */
input:focus { outline: 2px solid green; }

10. Seletores CSS: como escolher os elementos

O seletor fica antes das chaves e responde à pergunta: “quais elementos devem receber estas regras?” Combine seletores para atingir exatamente o elemento pretendido, sem depender de estilos repetidos.

Seletores básicos e agrupamento

*
Seletor universal: corresponde a todos os elementos. É comum para normalizar cálculos, mas usar muitas regras globais pode dificultar a manutenção. 
* {
    box-sizing: border-box;
}
p
Seletor de elemento: seleciona todas as tags com aquele nome. É bom para estilos gerais de elementos HTML. 
p {
    line-height: 1.6;
}
.aviso
Seletor de classe: o ponto procura um valor do atributo class. Classes podem ser reutilizadas em vários elementos. 
.aviso {
    border-left: 4px solid orange;
}
#principal
Seletor de id: o jogo da velha procura o atributo id. Use id único para âncoras ou uma região singular; para estilos reutilizáveis, prefira classes. 
#principal {
    max-width: 70rem;
}
A, B
Lista de seletores: a vírgula aplica a mesma regra a vários seletores independentes. 
h1, h2, h3 {
    font-family: system-ui, sans-serif;
}

Combinadores: relação entre elementos

A B
Descendente: seleciona B em qualquer profundidade dentro de A. 
article a {
    color: seagreen;
}
A > B
Filho direto: seleciona B somente quando o pai imediato é A. 
nav > ul {
    display: flex;
}
A + B
Irmão adjacente: seleciona o primeiro B que aparece imediatamente depois de A, compartilhando o mesmo pai. 
h2 + p {
    margin-top: 0;
}
A ~ B
Irmãos seguintes: seleciona todos os B que vêm depois de A e têm o mesmo pai; não precisam estar colados. 
h2 ~ p {
    color: #64748b;
}

Seletores de atributos

[disabled]
Seleciona qualquer elemento que tenha o atributo, independentemente do valor. 
button[disabled] {
    cursor: not-allowed;
    opacity: 0.55;
}
[type="email"]
= pede igualdade exata com o valor completo. 
input[type="email"] {
    border-color: royalblue;
}
[href^="https"]
^= seleciona valores que começam com o texto informado, útil para distinguir links externos. 
a[href^="https"] {
    text-decoration-style: dotted;
}
[src$=".svg"]
$= seleciona valores que terminam com o texto informado. 
img[src$=".svg"] {
    width: 2rem;
}
[class*="card"]
*= seleciona valores que contêm a sequência informada. Use com cautela: pode coincidir com nomes não pretendidos. 
[class*="card"] {
    border-radius: 1rem;
}
[class~="ativo"]
~= procura uma palavra inteira separada por espaços dentro do atributo. 
[class~="ativo"] {
    font-weight: 700;
}
[lang|="pt"]
|= seleciona o valor exato ou um valor que começa com ele seguido por hífen, por exemplo pt e pt-BR. 
[lang|="pt"] {
    quotes: "“" "”";
}

Pseudo-classes: estado ou posição

:hover, :active
:hover vale enquanto o ponteiro está sobre o elemento. :active vale enquanto ele está sendo pressionado. Não use hover como única forma de mostrar informação. 
button:hover {
    background: #d1fae5;
}

button:active {
    transform: translateY(1px);
}
:focus, :focus-visible
:focus seleciona o elemento que recebeu foco. :focus-visible destaca o foco quando o navegador considera útil, especialmente na navegação por teclado. Não remova o foco sem oferecer outro indicador. 
button:focus-visible {
    outline: 3px solid #65a30d;
    outline-offset: 3px;
}
:focus-within
Seleciona um contêiner quando ele ou qualquer descendente está com foco. 
.campo:focus-within {
    border-color: seagreen;
}
:link, :visited
:link aponta para links ainda não visitados; :visited estiliza links já visitados. Navegadores limitam algumas propriedades por privacidade. 
a:link { color: royalblue; }
a:visited { color: rebeccapurple; }
:checked
Seleciona caixas de seleção ou botões de opção marcados. 
input[type="checkbox"]:checked + label {
    color: seagreen;
}
:disabled, :enabled
Selecionam controles de formulário desativados ou habilitados. 
input:disabled { opacity: 0.5; }
input:enabled { cursor: text; }
:required, :optional
Identificam campos obrigatórios ou não obrigatórios segundo os atributos do formulário. 
input:required { border-left: 3px solid orange; }
input:optional { border-left: 3px solid #94a3b8; }
:valid, :invalid
Selecionam campos cuja validação HTML passou ou falhou. Use junto de mensagens de erro claras, não dependa apenas da cor. 
input:invalid { border-color: #dc2626; }
input:valid { border-color: #16a34a; }
:first-child, :last-child
Selecionam o primeiro ou o último filho de seu elemento pai. A posição é relativa aos irmãos dentro do mesmo pai. 
li:first-child { margin-top: 0; }
li:last-child { margin-bottom: 0; }
:nth-child()
Seleciona filhos por posição. Aceita números, odd, even e expressões como 3n + 1. 
tr:nth-child(even) { background: #f1f5f9; }
li:nth-child(3n + 1) { font-weight: 700; }
:not()
Seleciona elementos que não correspondem ao seletor dentro dos parênteses. 
button:not([disabled]) {
    cursor: pointer;
}
:is(), :where()
Agrupam alternativas dentro de um seletor. :is() assume a especificidade da alternativa mais específica; :where() tem especificidade zero e facilita sobrescrever o estilo depois. 
:is(h1, h2, h3) { line-height: 1.2; }
:where(article, section) p { max-width: 70ch; }
:has()
Seleciona um elemento com base no que existe dentro dele ou ao lado dele. É útil para reagir a um campo inválido ou a um item selecionado. 
.formulario:has(input:invalid) {
    border-color: #dc2626;
}
:root, :empty, :target
:root seleciona a raiz do documento e é comum para variáveis. :empty seleciona elemento sem filhos. :target seleciona o elemento apontado pela âncora da URL. 
:root { --cor: seagreen; }
.painel:empty { display: none; }
:target { scroll-margin-top: 2rem; }

Pseudo-elementos: parte visual do elemento

::before, ::after
Criam uma caixa decorativa antes ou depois do conteúdo. Normalmente precisam de content. Não use para conteúdo essencial, pois tecnologias assistivas podem não anunciá-lo como texto normal. 
.externo::after {
    content: " ↗";
}
::placeholder
Estiliza o texto de exemplo dentro de um campo vazio. Placeholder não substitui um rótulo persistente. 
input::placeholder {
    color: #64748b;
}
::selection, ::marker
::selection define as cores do texto selecionado pelo usuário. ::marker estiliza o marcador de listas. 
::selection { background: #bbf7d0; color: #14532d; }
li::marker { color: seagreen; }

Especificidade: qual regra vence?

Quando várias regras alteram a mesma propriedade do mesmo elemento, o navegador considera origem, importância, camadas, especificidade e ordem. Como aproximação, pense em três contadores: IDs, classes/atributos/pseudo-classes e elementos/pseudo-elementos. Um seletor com mais peso vence; em empate, normalmente vence a regra posterior. Evite resolver tudo com !important.

p { color: blue; }                 /* 0 IDs, 0 classes, 1 elemento */
.aviso { color: orange; }          /* 0 IDs, 1 classe, 0 elementos */
#principal .aviso { color: green; } /* 1 ID, 1 classe, 0 elementos */
Uma classe pode ser reutilizada. Um ID deve ser único por documento. Seletores mais simples costumam deixar o CSS mais fácil de manter.

11. Propriedades e valores: referência detalhada

O CSS tem centenas de propriedades, e algumas aceitam listas extensas de valores. Abaixo estão propriedades muito usadas, o papel de cada uma e os valores mais comuns. Uma propriedade abreviada como margin altera várias propriedades relacionadas de uma só vez.

Caixa, tamanho e espaçamento

width, height
Definem largura e altura. auto deixa o navegador calcular o tamanho. Também aceitam comprimentos, porcentagens e funções. Em imagens, defina só uma dimensão ou use aspect-ratio para evitar deformação. 
.painel { width: 100%; max-width: 60rem; }
.avatar { width: 4rem; height: 4rem; }
min-width, max-width, min-height, max-height
Impõem limites mínimos e máximos. none é comum para remover um limite máximo. Servem para que um elemento cresça ou encolha sem ultrapassar o tamanho desejado. 
.conteudo {
    width: 100%;
    min-width: 0;
    max-width: 72rem;
}
.janela { max-height: 80vh; }
margin, padding
margin cria espaço do lado de fora; padding, do lado de dentro. Aceitam comprimento, porcentagem e auto (principalmente para margin). Com quatro valores, a ordem é topo, direita, baixo, esquerda. 
.caixa {
    margin: 0 auto;
    padding: 1rem 1.5rem;
}
.quatro-lados { padding: 1rem 2rem 3rem 4rem; }
box-sizing
content-box soma padding e borda além da largura declarada. border-box inclui conteúdo, padding e borda no tamanho declarado; costuma tornar layouts mais previsíveis. 
* { box-sizing: border-box; }
border-width, border-style, border-color
Controlam espessura, aparência e cor separadamente. Estilos comuns: none, solid, dashed, dotted e double. Sem um estilo diferente de none, a borda não aparece. 
.cartao {
    border-width: 1px;
    border-style: solid;
    border-color: #94a3b8;
}
border-radius
Arredonda os cantos. Aceita comprimentos ou porcentagens; 50% cria um círculo quando largura e altura são iguais. Pode receber um, dois, três ou quatro valores. 
.botao { border-radius: 999px; }
.circulo { width: 4rem; aspect-ratio: 1; border-radius: 50%; }

Display e alinhamento

display
block cria uma caixa de bloco; inline participa da linha do texto; inline-block fica na linha mas aceita dimensões; flex e grid ativam esses layouts; none remove a caixa da página. Use contents com cuidado: remove a caixa do elemento, não seu conteúdo. 
.menu { display: flex; }
.grade { display: grid; }
.oculto { display: none; }
flex-direction, flex-wrap
flex-direction escolhe a direção: row, row-reverse, column ou column-reverse. flex-wrap escolhe se os itens quebram linha: nowrap, wrap ou wrap-reverse. 
.menu {
    display: flex;
    flex-direction: row;
    flex-wrap: wrap;
}
justify-content
Distribui itens no eixo principal do flexbox ou no eixo de linhas do grid. Valores comuns: start, end, center, space-between, space-around, space-evenly. Espaços só são distribuídos se houver espaço livre. 
.menu {
    display: flex;
    justify-content: space-between;
}
align-items, align-self
align-items alinha todos os filhos no eixo cruzado; align-self altera um filho individual. Valores mais comuns: stretch, start, end, center e baseline. 
.linha { display: flex; align-items: center; }
.item-especial { align-self: flex-start; }
flex, flex-grow, flex-shrink, flex-basis
flex é abreviação de crescimento, redução e tamanho inicial. Exemplo 1 1 220px: pode crescer, pode encolher e começa com base de 220 px. flex: 1 normalmente divide o espaço disponível entre os itens. 
.item { flex: 1 1 220px; }
.item-fixo { flex: 0 0 12rem; }
grid-template-columns, grid-template-rows
Desenham colunas e linhas do grid. Use comprimentos fixos, porcentagens, auto, fr, repeat() e minmax(). fr divide o espaço que sobrou. 
.grade {
    display: grid;
    grid-template-columns: repeat(3, minmax(0, 1fr));
    grid-template-rows: auto 1fr;
}
grid-auto-flow
Controla como itens que não têm posição explícita são colocados: row preenche linhas, column preenche colunas e dense tenta preencher espaços vazios. 
.grade { grid-auto-flow: row; }
.compacta { grid-auto-flow: row dense; }
gap, row-gap, column-gap
Definem o espaço entre itens de flexbox, grid ou colunas de texto. Um valor aplica o mesmo espaço; dois valores são linha e coluna. Não adicionam espaço nas bordas externas do contêiner. 
.grade { gap: 1rem; }
.grade { row-gap: 1rem; column-gap: 2rem; }

Posicionamento e rolagem

position
static é o fluxo normal; relative permite deslocamento e serve de referência para filhos; absolute sai do fluxo; fixed fica preso à janela; sticky acompanha a rolagem até um limite. Para sticky, indique um limite, como top: 0. 
.pai { position: relative; }
.dica { position: absolute; top: 100%; left: 0; }
.cabecalho { position: sticky; top: 0; }
top, right, bottom, left, inset
Definem distância a partir das bordas do bloco de referência quando o posicionamento permite deslocamento. inset é a abreviação; inset: 0 encosta nos quatro lados. 
.overlay {
    position: absolute;
    inset: 0;
}
z-index
Controla a ordem de sobreposição dentro de um contexto de empilhamento. Valores maiores tendem a ficar à frente, mas contextos diferentes não são comparados como uma lista única. 
.menu { position: relative; z-index: 2; }
.fundo { position: relative; z-index: 1; }
overflow, overflow-x, overflow-y
visible deixa conteúdo sair; hidden corta; clip corta sem criar rolagem; scroll sempre cria área rolável; auto só mostra rolagem quando necessária. Use os eixos para controlar horizontal e vertical separadamente. 
.lista { max-height: 20rem; overflow-y: auto; }
.tabela { overflow-x: auto; }
scroll-margin, scroll-padding
scroll-margin reserva distância ao redor do elemento que será alcançado. scroll-padding reserva espaço dentro do contêiner de rolagem, útil quando há uma barra fixa no topo. 
html { scroll-padding-top: 5rem; }
h2 { scroll-margin-top: 1rem; }

Texto e fonte

font-family
Define a família da fonte. Escreva alternativas em ordem: se a primeira não existir, o navegador tenta a próxima. Nomes com espaços precisam de aspas; termine com uma família genérica como sans-serif, serif ou monospace. 
body {
    font-family: "Segoe UI", Arial, sans-serif;
}
code { font-family: Consolas, monospace; }
font-size
Define o tamanho das letras. Pode usar comprimentos como px, rem, em, porcentagem ou palavras como small, large, smaller e larger. rem costuma escalar de forma previsível conforme a fonte raiz. 
body { font-size: 1rem; }
h1 { font-size: clamp(2rem, 5vw, 4rem); }
font-weight, font-style
font-weight controla o peso: normal, bold ou números de 1 a 1000 se a fonte suportar. font-style usa normal, italic ou oblique. 
.normal { font-weight: 400; font-style: normal; }
.destaque { font-weight: 700; font-style: italic; }
text-align
Alinha texto em linha: start segue o idioma, end é o lado oposto, left/right são físicos, center centraliza e justify ajusta os espaços para alinhar as duas margens. 
p { text-align: start; }
.legenda { text-align: center; }
text-decoration
Adiciona linha e seus detalhes. Pode combinar tipo, estilo, cor e espessura: underline, overline, line-through, solid, dotted, wavy ou none. 
a { text-decoration: underline; }
a:hover { text-decoration: underline wavy currentColor; }
text-transform
Altera a aparência das letras sem mudar o texto original: uppercase, lowercase, capitalize ou none. 
.rotulo { text-transform: uppercase; }
white-space
Controla espaços e quebras de linha. normal quebra normalmente; nowrap mantém uma linha; pre preserva espaços e quebras; pre-wrap preserva mas permite quebra; pre-line preserva quebras, colapsando espaços repetidos. 
.codigo { white-space: pre-wrap; }
.uma-linha { white-space: nowrap; }
overflow-wrap, word-break
overflow-wrap: anywhere permite quebrar palavras longas para evitar rolagem horizontal. word-break controla a quebra dentro das palavras; use valores adequados ao idioma para não prejudicar a leitura. 
.texto {
    overflow-wrap: anywhere;
    word-break: normal;
}
letter-spacing, word-spacing
Aumentam ou diminuem espaços entre letras ou palavras. Aceitam comprimentos e podem receber valor negativo; excessos tornam o texto difícil de ler. 
.selo { letter-spacing: 0.08em; }
.paragrafo { word-spacing: 0.1em; }

Cores, fundo e efeitos visuais

color
Define a cor do texto e também o valor herdado por currentColor. Formatos comuns: nomes, hexadecimal curto/longo, rgb(), hsl() e oklch(); alfa controla transparência. 
color: #14532d;
color: rgb(20 83 45 / 90%);
color: hsl(140 60% 25%);
background
É uma abreviação para cor, imagem/gradiente, posição, repetição, tamanho e outras opções do fundo. Várias imagens podem ser separadas por vírgula; a primeira fica na camada de cima. 
background: #f8fafc;
background: linear-gradient(135deg, #ecfccb, #dcfce7);
background-size
cover cobre a caixa, cortando o excesso; contain mostra a imagem inteira, podendo sobrar espaço; auto mantém seu tamanho natural; também aceita largura e altura explícitas. 
.banner { background-size: cover; }
.icone { background-size: 2rem 2rem; }
background-position, background-repeat
Posicionam a imagem usando palavras como center, top, left ou comprimentos. Repetição aceita repeat, no-repeat, repeat-x, repeat-y, space e round. 
.banner {
    background-position: center top;
    background-repeat: no-repeat;
}
opacity, visibility
opacity varia de 0 (transparente) a 1 (opaco), mas o elemento continua ocupando espaço e pode receber clique. visibility aceita visible, hidden e collapse; hidden mantém o espaço. 
.fantasma { opacity: 0; }
.hidden { visibility: hidden; }
box-shadow, text-shadow
Desenham sombras sem alterar o tamanho do layout. A ordem comum é deslocamento horizontal, vertical, desfoque, expansão (só para caixa) e cor. inset cria sombra interna na caixa; várias sombras são separadas por vírgula. 
.cartao { box-shadow: 0 8px 24px rgb(0 0 0 / 18%); }
.texto { text-shadow: 0 1px 2px rgb(0 0 0 / 30%); }
filter, backdrop-filter
filter modifica o elemento; backdrop-filter modifica o que aparece atrás dele. Funções comuns: blur(), brightness(), contrast(), grayscale(), sepia() e drop-shadow(). Pode haver impacto de desempenho com blur grande. 
.imagem { filter: grayscale(1); }
.vidro { backdrop-filter: blur(12px); }
object-fit, object-position
Controlam mídia dentro da caixa. fill pode distorcer; contain mostra tudo; cover preenche cortando; none preserva tamanho natural; scale-down escolhe entre none e contain. object-position move o ponto visível. 
img {
    width: 100%;
    height: 14rem;
    object-fit: cover;
    object-position: center 30%;
}
transform
Move, gira, inclina ou redimensiona visualmente sem reorganizar o espaço ao redor. Aceita translate(), rotate(), scale(), skew() e transformações 3D. none remove transformação. 
.cartao:hover { transform: translateY(-4px) scale(1.02); }

Interação, estado e movimento

outline, outline-offset
Desenham um contorno fora da caixa sem alterar o espaço ocupado. outline aceita largura, estilo e cor; estilos incluem solid, dotted e dashed. Não remova o contorno de foco sem substituí-lo. 
button:focus-visible {
    outline: 3px solid #65a30d;
    outline-offset: 3px;
}
cursor
Escolhe o ponteiro: auto, default, pointer, text, wait, move, grab, grabbing, not-allowed, entre outros. O cursor não substitui um botão real nem informa sozinho que a ação está indisponível. 
button { cursor: pointer; }
.arrastavel { cursor: grab; }
.desativado { cursor: not-allowed; }
pointer-events
auto mantém o comportamento normal; none faz o ponteiro atravessar o elemento, permitindo atingir o que está atrás. Útil em decoração sobreposta, mas inadequado para botões e links que precisam ser clicáveis. 
.decoracao { pointer-events: none; }
transition
Suaviza uma mudança entre valores. Cada item pode indicar propriedade, duração, curva e atraso. Curvas comuns: ease, linear, ease-in, ease-out, ease-in-out. Prefira animar transform e opacity a dimensões pesadas. 
button {
    transition: background-color 180ms ease,
                transform 180ms ease;
}
animation
Executa etapas definidas em @keyframes. Abrevia nome, duração, curva, atraso, repetições, direção, preenchimento e estado. Repetições podem ser número ou infinite; use movimento com moderação e respeite preferências de acessibilidade. 
@keyframes aparecer {
    from { opacity: 0; }
    to { opacity: 1; }
}

.painel { animation: aparecer 300ms ease-out both; }
accent-color
Define a cor de destaque nativa de controles como checkbox, radio, range e progress. O navegador mantém o controle e sua interação padrão. 
input[type="checkbox"] {
    accent-color: seagreen;
}
