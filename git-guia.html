Como o Git funciona

Git registra snapshots das alterações em um repositório local. O fluxo básico passa por working tree, stage e commit.

git status
git add .
git commit -m "Adiciona nova funcionalidade"

1. Configuração

git init
Inicializa um repositório no diretório atual. 
git init
git config
Define nome e email usados nos commits. 
git config --global user.name "Seu Nome"
git config --global user.email "seu@email.com"
git config --global core.editor code
git config --list
Lista configurações efetivas. 
git config --global --list
git config --list
.gitignore
Define arquivos que não devem ser rastreados. 
node_modules/
.env
dist/
*.log

2. Alterações e commits

git status
Mostra arquivos alterados, preparados e não rastreados. 
git status
git status -s
git diff
Mostra alterações ainda não adicionadas ao stage. 
git diff
git diff --staged
git add
Move alterações para o stage. 
git add index.html
git add .
git add -A
git commit
Cria um snapshot permanente e identificável. 
git commit -m "Descrição objetiva"
git commit -am "Altera arquivos rastreados"
git rm
Remove um arquivo do diretório e do rastreamento. 
git rm arquivo.txt
git rm --cached .env

3. Branches

git branch
Lista, cria ou remove branches locais. 
git branch
git branch feature/login
git branch -d feature/login
git branch -m novo-nome
git switch
Troca de branch; -c cria e troca. 
git switch main
git switch -c feature/login
git merge
Integra outro branch ao branch atual. 
git switch main
git merge feature/login
git rebase
Move ou reaplica commits sobre outra base. Evite rebase em branches compartilhados já enviados. 
git switch feature/login
git rebase main

4. Repositórios remotos

git remote
Registra e consulta servidores remotos. 
git remote -v
git remote add origin URL_DO_REPOSITORIO
git remote set-url origin NOVA_URL
git clone
Copia um repositório remoto para sua máquina. 
git clone URL
git clone URL minha-pasta
git fetch
Busca referências remotas sem mesclá-las automaticamente. 
git fetch
git fetch origin
git pull
Busca e integra as alterações remotas. 
git pull
git pull --rebase origin main
git push
Envia commits para o remoto. 
git push
git push -u origin main
git push origin feature/login

5. Consultar histórico

git log
Exibe commits recentes. 
git log
git log --oneline --decorate --graph
git log --stat
git log -p arquivo.html
git show
Mostra os detalhes de um commit ou objeto. 
git show
git show HASH_DO_COMMIT
git blame
Mostra quem alterou cada linha de um arquivo. 
git blame index.html

6. Recuperação e desfazer

git restore
Desfaz alterações em arquivos, com opções para a área staged. 
git restore index.html
git restore --staged index.html
git revert
Cria um novo commit que desfaz outro sem apagar histórico. 
git revert HASH_DO_COMMIT
git reset
--soft preserva staged; --mixed preserva arquivos; --hard remove alterações. Use com cuidado. 
git reset --soft HEAD~1
git reset HEAD~1
git reset --hard HEAD~1
git stash
Guarda alterações temporariamente sem commit. 
git stash
git stash push -m "Trabalho em andamento"
git stash list
git stash pop
git stash apply stash@{0}
Antes de reset --hard, confirme o conteúdo não salvo e prefira stash ou revert.

7. Outros comandos úteis

git tag
Marca um ponto importante no histórico, geralmente uma versão pronta para publicar. 
git tag
git tag v1.0.0
git tag -a v1.0.0 -m "Primeira versão"
git push origin v1.0.0
git push origin --tags

A tag anotada (-a) guarda autor e mensagem. Tags não são enviadas junto com git push normal, então envie-as explicitamente.

git reflog
Mostra movimentos recentes do HEAD. Pode ajudar a localizar um commit após uma troca de branch ou reset acidental. 
git reflog
git show HEAD@{1}

Use primeiro para localizar o commit; antes de restaurar, confira se ele contém o trabalho desejado.

git cherry-pick
Copia um commit específico para o branch atual, sem mesclar o branch inteiro. 
git switch main
git cherry-pick HASH_DO_COMMIT

Útil para trazer uma correção isolada. Se aparecer conflito, resolva os arquivos e finalize com git cherry-pick --continue.

git clean
Apaga arquivos não rastreados. Primeiro veja o que seria removido; a opção -f realmente executa. 
git clean -n
git clean -nd
git clean -fd

Cuidado: arquivos não rastreados removidos não fazem parte do histórico normal do Git e podem não ser recuperáveis.

git diff entre branches
Compara o conteúdo de dois branches ou commits antes de integrar mudanças. 
git diff main..feature/login
git diff --name-only main..feature/login
git diff HEAD~1
git log filtrado
Encontra commits por autor, data ou mensagem. 
git log --author="Ana"
git log --since="2 weeks ago"
git log --grep="login" --oneline
git ls-files
Lista os arquivos que o Git já está rastreando. 
git ls-files
git ls-files "*.html"
git mv
Renomeia ou move um arquivo e prepara a alteração para o próximo commit. 
git mv antigo.txt novo.txt
git status
git remote prune
Remove referências locais a branches remotos que já foram apagados no servidor. Não apaga seus arquivos locais. 
git fetch --prune
git remote prune origin
git bisect
Ajuda a descobrir qual commit introduziu um problema, comparando versões boas e ruins. 
git bisect start
git bisect bad
git bisect good HASH_DE_UMA_VERSAO_BOA
git bisect reset

Entre os comandos, teste o projeto e marque cada versão com git bisect good ou git bisect bad.

git archive
Gera um arquivo compactado do conteúdo de um commit ou branch, sem a pasta interna .git. 
git archive --format=zip --output=projeto.zip HEAD
